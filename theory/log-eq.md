## მთავარი იდეა

ლოგარითმული განტოლება ერთი ფაქტით იხსნება: ლოგარითმული ფუნქცია მონოტონურია, ამიტომ $\log_af=\log_ag$ ნიშნავს $f=g$-ს — **თუ** $f$ და $g$ დადებითია. ლოგარითმების თვისებების გამოყენებისას განსაზღვრის არე შეიძლება შეიცვალოს, ამიტომ ზედმეტი ფესვები ჩნდება. ორი ძირითადი საფრთხე: დმა-ს დავიწყება და ფესვის შემოწმების გამოტოვება.

## განმარტებები და ფორმულები

:::theorem ძირითადი ტოლფასობები
$a>0$, $a\neq1$:
$$\log_af(x)=b\iff f(x)=a^b;$$
$$\log_af(x)=\log_ag(x)\iff\begin{cases}f(x)=g(x),\\ f(x)>0\end{cases}$$
(მეორე პირობად საკმარისია ერთ-ერთის დადებითობა — მეორე ტოლობიდან გამოდის).
:::

:::formula ხერხები
1. დმა: ყველა ლოგარითმის ქვეშ $>0$, ცვლადი ფუძე $>0$ და $\neq1$.
2. ლოგარითმების შეერთება: $\log_af+\log_ag=\log_a(fg)$ — მხოლოდ დმა-ზე (სადაც ორივე $>0$).
3. ჩანაცვლება: $t=\log_ax$ (ნებისმიერი ნამდვილი).
4. ერთ ფუძეზე გადასვლა: $\log_{a^2}x=\frac12\log_ax$, $\log_xa=\frac1{\log_ax}$.
5. ლოგარითმირება: $x^{\log x}=\ldots$-ის ორივე მხარის ლოგარითმი.
:::

## დამტკიცება

**$\log_af=\log_ag\iff f=g,\ f>0$.** ($\Rightarrow$) ლოგარითმები განსაზღვრულია, ამიტომ $f>0$; $y=\log_at$ მკაცრად მონოტონურია, ამიტომ ტოლი მნიშვნელობები ტოლ არგუმენტებს ნიშნავს: $f=g$. ($\Leftarrow$) თუ $f=g>0$, ორივე ლოგარითმი განსაზღვრულია და ტოლია. $\blacksquare$

**რატომ ჩნდება ზედმეტი ფესვი.** $\log_af+\log_ag$ განსაზღვრულია, როცა $f>0$ **და** $g>0$. $\log_a(fg)$ — როცა $fg>0$, რაც $f<0$, $g<0$ შემთხვევასაც მოიცავს. შეერთებით დმა ფართოვდება.

## ამოხსნილი მაგალითები

:::example მარტივი
ამოხსენით $\log_3(2x-1)=2$.
:::solution
$2x-1=9$, $x=5$ ($2x-1=9>0$).

**პასუხი:** $x=5$.
:::
:::

:::example საშუალო
ამოხსენით $\log_2(x-2)+\log_2(x-3)=1$.
:::solution
დმა: $x>3$. შეერთება: $\log_2\big((x-2)(x-3)\big)=1$, ანუ $(x-2)(x-3)=2$, $x^2-5x+4=0$: $x=1$ ან $x=4$.

$x=1$ დმა-ს გარეთაა.

**პასუხი:** $x=4$.
:::
:::

:::example რთული
ამოხსენით $\log_2^2x-\log_2x^3+2=0$.
:::solution
დმა: $x>0$. $\log_2x^3=3\log_2x$. $t=\log_2x$: $t^2-3t+2=0$, $t=1$ ან $t=2$.

$x=2$ ან $x=4$.

**პასუხი:** $x\in\{2;\,4\}$.
:::
:::

## გავრცელებული შეცდომები

- **დმა-ს დავიწყება.** საშუალო მაგალითში $x=1$ განტოლებას „აკმაყოფილებს“ შეერთების შემდეგ, მაგრამ საწყისში $\log_2(-1)$ არ არსებობს.
- **$\log_2^2x$ და $\log_2x^2$.** პირველი $(\log_2x)^2$-ია, მეორე — $2\log_2|x|$.
- **ფუძის პირობები.** $\log_x5$-ში $x>0$ და $x\neq1$.
- **„ლოგარითმის შეკვეცა“.** $\frac{\log x}{\log2}\neq\frac x2$.

## შეამოწმე თავი

:::check
ამოხსენით $\lg x=-2$.
:::answer
$x=10^{-2}=0{,}01$.
:::
:::

:::check
ამოხსენით $\log_5(x^2-4)=\log_5(3x)$.
:::answer
$x^2-3x-4=0$: $x=4$ ან $x=-1$. $3x>0$ მოითხოვს $x>0$. პასუხი: $x=4$.
:::
:::

:::check
ამოხსენით $\log_x 9=2$.
:::answer
$x^2=9$, $x>0$, $x\neq1$: $x=3$.
:::
:::
