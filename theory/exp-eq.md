## მთავარი იდეა

მაჩვენებლიან განტოლებაში უცნობი ხარისხის მაჩვენებელშია. მთავარი ფაქტი ასეთია: მაჩვენებლიანი ფუნქცია მონოტონურია, ამიტომ $a^{f(x)}=a^{g(x)}$ ნიშნავს $f(x)=g(x)$-ს. ყველა ხერხი ცდილობს ორივე მხარე ერთი ფუძის ხარისხად აქციოს, ან ჩანაცვლებით $t=a^x>0$ ალგებრულ განტოლებაზე დაიყვანოს.

## განმარტებები და ფორმულები

:::theorem ძირითადი ტოლფასობა
$a>0$, $a\neq1$:
$$a^{f(x)}=a^{g(x)}\iff f(x)=g(x).$$
:::

:::formula ტიპები და ხერხები
1. **ერთ ფუძეზე დაყვანა:** $4^x=8\iff2^{2x}=2^3$.
2. **საერთო მამრავლის გატანა:** $2^{x+2}-2^x=12\iff2^x(4-1)=12$.
3. **ჩანაცვლება $t=a^x>0$:** $4^x-3\cdot2^x+2=0\iff t^2-3t+2=0$.
4. **ერთგვაროვანი:** $a\cdot9^x+b\cdot6^x+c\cdot4^x=0$ — ვყოფთ $4^x$-ზე, $t=\left(\frac32\right)^x$.
5. **ლოგარითმირება:** $2^x=5\iff x=\log_25$.
6. **მონოტონურობა:** თუ მარცხნივ ზრდადი, მარჯვნივ კლებადი ფუნქციაა, ფესვი არაუმეტეს ერთია — შეგვიძლია გამოვიცნოთ.
:::

:::note
ჩანაცვლების შემდეგ $t$-ის უარყოფითი ან ნულოვანი მნიშვნელობები გამოირიცხება: $a^x>0$.
:::

## დამტკიცება

**ძირითადი ტოლფასობა.** ($\Leftarrow$) ცხადია. ($\Rightarrow$) ვთქვათ $a^{f(x_0)}=a^{g(x_0)}$, მაგრამ $f(x_0)\neq g(x_0)$. $a\neq1$-ზე $y=a^t$ მკაცრად მონოტონურია, ამიტომ სხვადასხვა $t$-ზე სხვადასხვა მნიშვნელობას იღებს — წინააღმდეგობა. $\blacksquare$

$a=1$-ზე ტოლფასობა არ მუშაობს: $1^{f}=1^{g}$ ყოველთვის.

## ამოხსნილი მაგალითები

:::example მარტივი
ამოხსენით $\left(\dfrac14\right)^{x-1}=8^{x}$.
:::solution
$2^{-2(x-1)}=2^{3x}\iff-2x+2=3x\iff x=\frac25$.

**პასუხი:** $x=\dfrac25$.
:::
:::

:::example საშუალო
ამოხსენით $4^x-3\cdot2^{x+1}+8=0$.
:::solution
$2^{x+1}=2\cdot2^x$. $t=2^x>0$: $t^2-6t+8=0$, $t=2$ ან $t=4$. $x=1$ ან $x=2$.

**პასუხი:** $x\in\{1;\,2\}$.
:::
:::

:::example რთული
ამოხსენით $3\cdot4^x+2\cdot9^x=5\cdot6^x$.
:::solution
გავყოთ $4^x>0$-ზე: $3+2\left(\frac94\right)^x=5\left(\frac32\right)^x$. $t=\left(\frac32\right)^x>0$:
$$2t^2-5t+3=0\iff t=1\ \text{ან}\ t=\frac32.$$
$t=1\Rightarrow x=0$; $t=\frac32\Rightarrow x=1$.

შემოწმება $x=1$-ზე: $12+18=30=5\cdot6$.

**პასუხი:** $x\in\{0;\,1\}$.
:::
:::

## გავრცელებული შეცდომები

- **$t\le0$-ის დატოვება.** $2^x=-3$ ამონახსნი არ აქვს.
- **ხარისხების „შეკრება“.** $2^x+2^x=2\cdot2^x=2^{x+1}$, და არა $2^{2x}$ ან $4^x$.
- **სხვადასხვა ფუძე.** $2^x=3^x$-ის ფესვი $x=0$-ა (გავყოთ $3^x$-ზე: $\left(\frac23\right)^x=1$), და არა „ამონახსნი არ აქვს“.
- **$x+1$ მაჩვენებელში.** $2^{x+1}=2\cdot2^x$, და არა $2^x+1$.

## შეამოწმე თავი

:::check
ამოხსენით $3^{2x-1}=27$.
:::answer
$2x-1=3$, $x=2$.
:::
:::

:::check
ამოხსენით $2^{x+3}-2^x=56$.
:::answer
$2^x(8-1)=56$, $2^x=8$, $x=3$.
:::
:::

:::check
ამოხსენით $5^x=-5$.
:::answer
ამონახსნი არ არის: $5^x>0$.
:::
:::
