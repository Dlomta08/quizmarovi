## მთავარი იდეა

წრფივი ფუნქცია $y=kx+b$ არის ფუნქცია, რომლის გრაფიკი წრფეა. $k$ გვიჩვენებს, რამდენით იცვლება $y$, როცა $x$ ერთით იზრდება — ეს არის წრფის „დახრა“. $b$ არის ის წერტილი, სადაც წრფე ორდინატთა ღერძს კვეთს. ეს ორი რიცხვი წრფის ყველა თვისებას განსაზღვრავს: ზრდადობას, პარალელურობას, გადაკვეთებს.

## განმარტებები და ფორმულები

:::definition
**წრფივი ფუნქცია** არის $y=kx+b$ სახის ფუნქცია. $k$ — **კუთხური კოეფიციენტი**, $b$ — თავისუფალი წევრი. როცა $b=0$, მიიღება პირდაპირპროპორციულობა $y=kx$, რომლის გრაფიკი სათავეზე გადის.
:::

:::theorem გრაფიკი
$y=kx+b$-ის გრაფიკი წრფეა. ის ორდინატთა ღერძს კვეთს $(0;b)$ წერტილში. თუ $k\neq0$, აბსცისთა ღერძს კვეთს $\left(-\frac bk;0\right)$ წერტილში.
:::

:::formula $k$-ს აზრი
$$k=\frac{y_2-y_1}{x_2-x_1}$$
წრფის ნებისმიერი ორი წერტილისთვის. $k>0$ — ფუნქცია ზრდადია, $k<0$ — კლებადი, $k=0$ — მუდმივი ($y=b$, ჰორიზონტალური წრფე). $k=\operatorname{tg}\alpha$, სადაც $\alpha$ წრფის დახრის კუთხეა $Ox$ ღერძის დადებითი მიმართულების მიმართ.
:::

:::theorem ორი წრფის ურთიერთგანლაგება
$y=k_1x+b_1$ და $y=k_2x+b_2$:
- $k_1\neq k_2$ — იკვეთება ერთ წერტილში;
- $k_1=k_2$, $b_1\neq b_2$ — პარალელურია;
- $k_1=k_2$, $b_1=b_2$ — ემთხვევა.
ასევე: წრფეები მართობულია $\iff k_1k_2=-1$.
:::

:::formula ორ წერტილზე გამავალი წრფე
$$y-y_1=k(x-x_1),\qquad k=\frac{y_2-y_1}{x_2-x_1}\quad(x_1\neq x_2).$$
:::

## დამტკიცება

**$k$ ერთნაირია ყველა წყვილისთვის.** თუ $y_1=kx_1+b$ და $y_2=kx_2+b$, მაშინ $y_2-y_1=k(x_2-x_1)$, ანუ $\frac{y_2-y_1}{x_2-x_1}=k$ — არ არის დამოკიდებული წერტილების არჩევაზე.

**ზრდადობა.** თუ $x_1<x_2$, მაშინ $f(x_2)-f(x_1)=k(x_2-x_1)$. $x_2-x_1>0$, ამიტომ სხვაობის ნიშანი $k$-ს ნიშანია: $k>0$-ზე $f(x_2)>f(x_1)$ — ზრდადია. $\blacksquare$

**გადაკვეთა.** $k_1x+b_1=k_2x+b_2\iff(k_1-k_2)x=b_2-b_1$ — წრფივი განტოლება: $k_1\neq k_2$-ზე ერთი ამონახსნი, ხოლო $k_1=k_2$-ზე ან არც ერთი, ან უსასრულოდ ბევრი.

## ამოხსნილი მაგალითები

:::example მარტივი
იპოვეთ $y=-2x+6$ წრფის ღერძებთან გადაკვეთის წერტილები. ზრდადია თუ კლებადი?
:::solution
$x=0$: $y=6$ — წერტილი $(0;6)$. $y=0$: $x=3$ — წერტილი $(3;0)$. $k=-2<0$ — კლებადი.
:::
:::

:::example საშუალო
დაწერეთ $A(1;2)$ და $B(3;8)$ წერტილებზე გამავალი წრფის განტოლება.
:::solution
$k=\dfrac{8-2}{3-1}=3$. $y-2=3(x-1)$, ანუ $y=3x-1$.

შემოწმება: $3\cdot3-1=8$.

**პასუხი:** $y=3x-1$.
:::
:::

:::example რთული
$m$-ის რა მნიშვნელობისთვის არის $y=(m^2-3)x+m$ და $y=6x-3$ წრფეები პარალელური?
:::solution
პარალელურობა: $k_1=k_2$ და $b_1\neq b_2$. $m^2-3=6\iff m=\pm3$.

- $m=3$: $b_1=3\neq-3$ — პარალელურია.
- $m=-3$: $b_1=-3=b_2$ — წრფეები **ემთხვევა**, ეს პარალელურობა არ არის.

**პასუხი:** $m=3$.
:::
:::

## გავრცელებული შეცდომები

- **$k$-ს და $b$-ს არევა.** $y=6-2x$-ში $k=-2$, $b=6$ — ადგილს მნიშვნელობა არ აქვს.
- **$k$-ს გამოთვლა „უკუღმა“.** $\frac{x_2-x_1}{y_2-y_1}$ არასწორია; სწორია $\frac{y_2-y_1}{x_2-x_1}$, და მრიცხველსა და მნიშვნელში ერთნაირი რიგით.
- **დამთხვევა პარალელურობად.** ერთნაირი $k$ და ერთნაირი $b$ ერთსა და იმავე წრფეს ნიშნავს.
- **ვერტიკალური წრფე.** $x=2$ წრფეა, მაგრამ $y=kx+b$ სახით არ იწერება და ფუნქციის გრაფიკი არ არის.

## შეამოწმე თავი

:::check
ეკუთვნის თუ არა $A(2;1)$ წერტილი $y=3x-5$-ის გრაფიკს?
:::answer
კი: $3\cdot2-5=1$.
:::
:::

:::check
დაწერეთ $y=2x+1$-ის პარალელური წრფე, რომელიც სათავეზე გადის.
:::answer
$y=2x$.
:::
:::

:::check
$y=kx+2$ გადის $(4;0)$ წერტილზე. იპოვეთ $k$.
:::answer
$0=4k+2$, $k=-\frac12$.
:::
:::
