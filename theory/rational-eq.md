## მთავარი იდეა

რაციონალურ განტოლებაში უცნობი მნიშვნელშიც გვხვდება. მნიშვნელებზე გამრავლებით ის მრავალწევრულ განტოლებად იქცევა. მაგრამ ეს გამრავლება ყოველთვის ტოლფასი არ არის: თუ მამრავლი ნულდება, შეიძლება გაჩნდეს **ზედმეტი ფესვი**. ამიტომ რაციონალური განტოლების ამოხსნა ყოველთვის მთავრდება დასაშვებ მნიშვნელობებთან შემოწმებით.

## განმარტებები და ფორმულები

:::definition
განტოლებას, რომლის ორივე მხარე რაციონალური გამოსახულებაა, **რაციონალური** ეწოდება. მისი **დმა** არის ის $x$-ები, რომლებზეც ყველა მნიშვნელი ნულისგან განსხვავდება.
:::

:::theorem წილადი ნულის ტოლია
$$\frac{P(x)}{Q(x)}=0\iff P(x)=0\ \text{და}\ Q(x)\neq0.$$
:::

:::formula ამოხსნის გეგმა
1. ვიპოვოთ დმა.
2. ყველა წევრი გადავიტანოთ ერთ მხარეს და მივიყვანოთ საერთო მნიშვნელზე, ან ორივე მხარე გავამრავლოთ საერთო მნიშვნელზე.
3. ამოვხსნათ მიღებული მრავალწევრული განტოლება.
4. გამოვრიცხოთ ფესვები, რომლებიც დმა-ს არ ეკუთვნის.
:::

:::note ჩანაცვლება
თუ განტოლებაში მეორდება ერთი და იგივე გამოსახულება, შემოვიღოთ ახალი უცნობი. ხშირი შემთხვევაა $t+\dfrac1t$, სადაც $t$ თავად წილადია.
:::

## დამტკიცება

**რატომ ჩნდება ზედმეტი ფესვი.** ვთქვათ $\frac{P}{Q}=0$ გავამრავლეთ $Q$-ზე და მივიღეთ $P=0$. ყოველი ამონახსნი საწყისი განტოლებისა ამ ახალსაც აკმაყოფილებს. პირიქით კი ყოველთვის არა: თუ $P(x_0)=0$ და $Q(x_0)=0$, მაშინ $x_0$ ახალი განტოლების ფესვია, საწყისში კი $\frac00$ განსაზღვრული არ არის.

ამიტომ ტოლფასობა სრულდება მხოლოდ დმა-ზე: იქ $Q\neq0$, და $Q$-ზე გამრავლება/გაყოფა ტოლფასი გარდაქმნაა. $\blacksquare$

## ამოხსნილი მაგალითები

:::example მარტივი
ამოხსენით $\dfrac{3}{x-2}=\dfrac{2}{x+1}$.
:::solution
დმა: $x\neq2$, $x\neq-1$. პროპორციის თვისებით $3(x+1)=2(x-2)$, $3x+3=2x-4$, $x=-7$. ის დმა-ს ეკუთვნის.

**პასუხი:** $x=-7$.
:::
:::

:::example საშუალო
ამოხსენით $\dfrac{x}{x-3}-\dfrac{3}{x+3}=\dfrac{18}{x^2-9}$.
:::solution
დმა: $x\neq\pm3$. საერთო მნიშვნელია $(x-3)(x+3)$. გავამრავლოთ:
$$x(x+3)-3(x-3)=18\iff x^2+9=18\iff x^2=9.$$
$x=\pm3$, მაგრამ ორივე დმა-ს გარეთაა.

**პასუხი:** ამონახსნი არ არის.
:::
:::

:::example რთული
ამოხსენით $\dfrac{x}{x+1}+\dfrac{x+1}{x}=\dfrac52$.
:::solution
დმა: $x\neq0$, $x\neq-1$. აღვნიშნოთ $t=\dfrac{x}{x+1}$; მაშინ მეორე წილადია $\dfrac1t$:
$$t+\frac1t=\frac52\iff 2t^2-5t+2=0\iff t=2\ \text{ან}\ t=\frac12.$$
- $\dfrac{x}{x+1}=2\Rightarrow x=2x+2\Rightarrow x=-2$.
- $\dfrac{x}{x+1}=\dfrac12\Rightarrow 2x=x+1\Rightarrow x=1$.

ორივე დმა-ს ეკუთვნის. შემოწმება $x=1$-ზე: $\frac12+2=\frac52$.

**პასუხი:** $x\in\{-2;\,1\}$.
:::
:::

## გავრცელებული შეცდომები

- **შემოწმების გამოტოვება.** საშუალო მაგალითში შემოწმების გარეშე პასუხი იქნებოდა $\pm3$ — სრულიად არასწორი.
- **„წილადი ნულია, როცა მნიშვნელი ნულია“.** პირიქით: წილადი ნულია, როცა **მრიცხველი** ნულია (და მნიშვნელი — არა).
- **„ჯვარედინი გამრავლება“ ბევრ წევრზე.** $\frac ab=\frac cd$-ის წესი მხოლოდ მაშინ მუშაობს, როცა თითო მხარეს ერთი წილადია.
- **დმა-ს დავიწყება შეკვეცის შემდეგ.** $\frac{x^2-1}{x-1}=2$-ში შეკვეცით მიიღება $x+1=2$, $x=1$. მაგრამ $x=1$ დმა-ს არ ეკუთვნის — ამონახსნი არ არის.

## შეამოწმე თავი

:::check
ამოხსენით $\dfrac{x^2-4}{x-2}=0$.
:::answer
მრიცხველი ნულია $x=\pm2$-ზე, მაგრამ $x=2$-ზე მნიშვნელიც ნულია. პასუხი: $x=-2$.
:::
:::

:::check
ამოხსენით $\dfrac{2}{x-1}=\dfrac{x+1}{x-1}$.
:::answer
$x+1=2$, $x=1$ — მაგრამ ის დმა-ს არ ეკუთვნის. ამონახსნი არ არის.
:::
:::

:::check
რომელი რიცხვები არ ეკუთვნის $\dfrac1x+\dfrac{1}{x^2-5x}=2$ განტოლების დმა-ს?
:::answer
$x=0$ და $x=5$.
:::
:::
