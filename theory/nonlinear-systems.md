## მთავარი იდეა

არაწრფივ სისტემაში ერთი განტოლება მაინც არ არის წრფივი. ზოგადი რეცეპტი არ არსებობს, მაგრამ რამდენიმე ტიპური სტრუქტურა გვხვდება ხშირად. ჩასმა მუშაობს, როცა ერთი განტოლება წრფივია. სიმეტრიულ სისტემებში უცნობის ნაცვლად ვიღებთ $x+y$-სა და $xy$-ს. ერთგვაროვან განტოლებაში ვსვამთ $x=ty$-ს. გეომეტრიულად ამონახსნები წირების გადაკვეთის წერტილებია.

## განმარტებები და ფორმულები

:::formula ჩასმის ხერხი
თუ ერთი განტოლება წრფივია, მისგან გამოვსახოთ ერთი უცნობი და ჩავსვათ მეორეში. მიიღება ერთუცნობიანი (ხშირად კვადრატული) განტოლება.
:::

:::definition
სისტემა **სიმეტრიულია**, თუ $x$-ისა და $y$-ის ადგილების გაცვლისას არ იცვლება. ასეთი სისტემა ჩაიწერება $u=x+y$ და $v=xy$ ცვლადებით. გამოიყენება:
$$x^2+y^2=u^2-2v,\qquad x^3+y^3=u^3-3uv.$$
:::

:::theorem
თუ $x+y=u$ და $xy=v$, მაშინ $x$ და $y$ არის $z^2-uz+v=0$ განტოლების ფესვები (ნებისმიერი თანმიმდევრობით).
:::

:::definition
განტოლება $ax^2+bxy+cy^2=0$ **ერთგვაროვანია** (ყველა წევრი მეორე ხარისხისაა). თუ $y\neq0$, ჩასმა $x=ty$ და $y^2$-ზე გაყოფა იძლევა $at^2+bt+c=0$.
:::

## დამტკიცება

თეორემა ვიეტის შებრუნებული თეორემაა: $(z-x)(z-y)=z^2-(x+y)z+xy=z^2-uz+v$. ამიტომ $x$ და $y$ ამ სამწევრის ფესვებია.

შედეგად, სიმეტრიული სისტემის ამოხსნა ორ ნაბიჯად იშლება: ვპოულობთ $(u;v)$ წყვილებს, შემდეგ თითოეულისთვის ვხსნით $z^2-uz+v=0$-ს. თუ ფესვები $z_1\neq z_2$, ვიღებთ ორ ამონახსნს: $(z_1;z_2)$ და $(z_2;z_1)$. $\blacksquare$

## ამოხსნილი მაგალითები

:::example მარტივი
ამოხსენით $\begin{cases}x+y=5,\\ xy=6.\end{cases}$
:::solution
$x$ და $y$ არის $z^2-5z+6=0$-ის ფესვები: $2$ და $3$.

**პასუხი:** $(2;\,3)$ და $(3;\,2)$.
:::
:::

:::example საშუალო
ამოხსენით $\begin{cases}x^2+y^2=25,\\ x+y=7.\end{cases}$
:::solution
$x^2+y^2=(x+y)^2-2xy$, ამიტომ $25=49-2xy$, $xy=12$. $z^2-7z+12=0$: $z=3$ ან $z=4$.

**პასუხი:** $(3;\,4)$ და $(4;\,3)$.
:::
:::

:::example რთული
ამოხსენით $\begin{cases}x^2-3xy+2y^2=0,\\ x^2+y^2=20.\end{cases}$
:::solution
პირველი განტოლება ერთგვაროვანია და იშლება: $(x-y)(x-2y)=0$. ($y=0$-ზე პირველიდან $x=0$, მაგრამ $0\neq20$ — ასეთი ამონახსნი არ არის.)

- $x=y$: $2y^2=20$, $y=\pm\sqrt{10}$.
- $x=2y$: $5y^2=20$, $y=\pm2$.

**პასუხი:** $(\sqrt{10};\,\sqrt{10})$, $(-\sqrt{10};\,-\sqrt{10})$, $(4;\,2)$, $(-4;\,-2)$.
:::
:::

## გავრცელებული შეცდომები

- **$y$-ზე გაყოფა შემოწმების გარეშე.** ერთგვაროვან განტოლებაში ცალკე ვამოწმებთ $y=0$-ს.
- **წყვილის მეორე რიგის დავიწყება.** სიმეტრიულ სისტემაში $(2;3)$-თან ერთად $(3;2)$-იც ამონახსნია.
- **ნიშნის დაკარგვა.** $y^2=4$-დან $y=\pm2$ — და თითოეულ $y$-ს თავისი $x$ შეესაბამება.
- **პასუხის ცალ-ცალკე ჩაწერა.** „$x=3$ ან $4$, $y=3$ ან $4$“ არასწორია — ამონახსნები **წყვილებია**.

## შეამოწმე თავი

:::check
ამოხსენით $\begin{cases}x-y=1,\\ xy=6.\end{cases}$
:::answer
$x=y+1$: $y^2+y-6=0$, $y=2$ ან $y=-3$. პასუხი: $(3;\,2)$, $(-2;\,-3)$.
:::
:::

:::check
ამოხსენით $\begin{cases}x^2-y^2=8,\\ x-y=2.\end{cases}$
:::answer
$(x-y)(x+y)=8$, ამიტომ $x+y=4$. პასუხი: $(3;\,1)$.
:::
:::

:::check
რამდენი ამონახსნი აქვს სისტემას $x^2+y^2=1$, $y=2$?
:::answer
არც ერთი: $x^2=-3$. (წრფე $y=2$ წრეწირს არ კვეთს.)
:::
:::
