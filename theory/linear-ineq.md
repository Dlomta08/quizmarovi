## მთავარი იდეა

წრფივი უტოლობა იხსნება ისევე, როგორც წრფივი განტოლება. ერთადერთი სიფრთხილეა უარყოფით რიცხვზე გაყოფა — ამ დროს ნიშანი იცვლება. პასუხი ერთი რიცხვი კი არ არის, არამედ შუალედი. უტოლობათა სისტემის ამონახსნი შუალედების თანაკვეთაა, რომლის სანახავად ყველაზე მოსახერხებელია რიცხვითი ღერძი.

## განმარტებები და ფორმულები

:::definition
$ax>b$ (ან $<,\ \ge,\ \le$) სახის უტოლობას **წრფივი** ეწოდება. **ამონახსნი** არის ყველა $x$, რომლისთვისაც უტოლობა ჭეშმარიტია.
:::

:::theorem $ax>b$ უტოლობის ამონახსნები
- $a>0$: $x>\dfrac ba$;
- $a<0$: $x<\dfrac ba$ (ნიშანი იცვლება);
- $a=0$: $0>b$ — თუ $b<0$, ამონახსნია ყოველი $x$; თუ $b\ge0$, ამონახსნი არ არის.
:::

:::formula შუალედების ჩანაწერი
$$a<x<b\iff x\in(a;b),\qquad a\le x\le b\iff x\in[a;b],\qquad x\ge a\iff x\in[a;+\infty).$$
კვადრატული ფრჩხილი — ბოლო შედის, მრგვალი — არ შედის. $\infty$-თან ფრჩხილი ყოველთვის მრგვალია.
:::

:::definition
უტოლობათა **სისტემის** ამონახსნი არის ყველა უტოლობის ამონახსნების თანაკვეთა. ორმაგი უტოლობა $p<f(x)<q$ ორი უტოლობის სისტემაა.
:::

## დამტკიცება

უტოლობის ამოხსნისას ვიყენებთ ტოლფას გარდაქმნებს — ისეთს, რომელიც ამონახსნთა სიმრავლეს არ ცვლის. რიცხვითი უტოლობების თვისებებიდან:
- ორივე მხარეზე ერთი და იმავე რიცხვის დამატება ტოლფასია (და შექცევადი: შეგვიძლია გამოვაკლოთ უკან);
- დადებით რიცხვზე გამრავლება ტოლფასია;
- უარყოფით რიცხვზე გამრავლება ტოლფასია **ნიშნის შეცვლით**.

ამიტომ $ax>b$, $a<0$: ორივე მხარე გავამრავლოთ $\frac1a<0$-ზე, მივიღებთ $x<\frac ba$. $\blacksquare$

## ამოხსნილი მაგალითები

:::example მარტივი
ამოხსენით $5-2x\ge11$.
:::solution
$-2x\ge6$. გავყოთ $-2$-ზე ნიშნის შეცვლით: $x\le-3$.

**პასუხი:** $x\in(-\infty;\,-3]$.
:::
:::

:::example საშუალო
ამოხსენით სისტემა $\begin{cases}2x+1\ge x-3,\\ 5-x>2.\end{cases}$
:::solution
პირველი: $x\ge-4$. მეორე: $-x>-3$, ანუ $x<3$. თანაკვეთა: $-4\le x<3$.

**პასუხი:** $x\in[-4;\,3)$.
:::
:::

:::example რთული
ამოხსენით $(a-1)x>a^2-1$ პარამეტრის ყველა მნიშვნელობისთვის.
:::solution
მარჯვენა მხარე $(a-1)(a+1)$-ია.

- $a>1$: გავყოთ დადებით $a-1$-ზე: $x>a+1$.
- $a<1$: გავყოთ უარყოფით $a-1$-ზე, ნიშანი იცვლება: $x<a+1$.
- $a=1$: $0\cdot x>0$ — ამონახსნი არ არის.

**პასუხი:** $a>1$: $x>a+1$; $a<1$: $x<a+1$; $a=1$: ამონახსნი არ არის.
:::
:::

## გავრცელებული შეცდომები

- **ნიშნის შეუცვლელობა.** უარყოფით რიცხვზე (ან უარყოფით პარამეტრზე) გაყოფისას ნიშანი უნდა შეიცვალოს.
- **სისტემა და ერთობლიობა.** სისტემის ამონახსნი **თანაკვეთაა** („და“), არა გაერთიანება („ან“).
- **ფრჩხილების არევა.** $x\le-3$ არის $(-\infty;-3]$ — $-3$ შედის, ამიტომ ფრჩხილი კვადრატულია.
- **პარამეტრიან გამოსახულებაზე გაყოფა.** მისი ნიშანი უცნობია — საჭიროა შემთხვევების განხილვა.

## შეამოწმე თავი

:::check
ამოხსენით $-2x\le6$.
:::answer
$x\ge-3$.
:::
:::

:::check
რამდენი მთელი ამონახსნი აქვს უტოლობას $1<2x-1\le7$?
:::answer
$2<2x\le8$, ანუ $1<x\le4$. მთელები: $2,3,4$ — სამი ამონახსნი.
:::
:::

:::check
ამოხსენით სისტემა $x>5$, $x<2$.
:::answer
თანაკვეთა ცარიელია — ამონახსნი არ არის.
:::
:::
