## მთავარი იდეა

მრავალწევრი არის ალგებრის ძირითადი „მასალა“: ერთწევრების ჯამი. მრავალწევრებს ვკრებთ, ვაკლებთ და ვამრავლებთ ისევე, როგორც რიცხვებს — მხოლოდ მსგავს წევრებს ვაერთიანებთ. ამ წესების ზუსტი ცოდნა აუცილებელია ყველა შემდეგი თემისთვის: ფორმულების, მამრავლებად დაშლის, განტოლებების.

## განმარტებები და ფორმულები

:::definition
**ერთწევრი** არის რიცხვისა და ცვლადების ნატურალური ხარისხების ნამრავლი, მაგალითად $-3a^2b^3$. რიცხვითი მამრავლი ($-3$) — **კოეფიციენტი**. ერთწევრის **ხარისხი** არის ცვლადების მაჩვენებლების ჯამი: $-3a^2b^3$-ის ხარისხია $5$.
:::

:::definition
ერთწევრებს, რომლებიც მხოლოდ კოეფიციენტით განსხვავდება, **მსგავსი** ეწოდება ($5x^2y$ და $-2x^2y$). მსგავსი წევრების შეკრებისას იკრიბება კოეფიციენტები: $5x^2y-2x^2y=3x^2y$.
:::

:::definition
**მრავალწევრი** ერთწევრების ჯამია. **სტანდარტული სახის** მრავალწევრში მსგავსი წევრები შეკრებილია. მრავალწევრის **ხარისხი** არის მისი წევრების ხარისხებიდან უდიდესი. ერთი ცვლადის მრავალწევრი ჩვეულებრივ იწერება ხარისხების კლების მიხედვით:
$$P(x)=a_nx^n+a_{n-1}x^{n-1}+\ldots+a_1x+a_0,\qquad a_n\neq0.$$
$a_n$ — უფროსი კოეფიციენტი, $a_0$ — თავისუფალი წევრი.
:::

:::formula მოქმედებები
- შეკრება/გამოკლება: ვხსნით ფრჩხილებს და ვაერთიანებთ მსგავს წევრებს. ფრჩხილის წინ მინუსი ყველა წევრის ნიშანს ცვლის.
- გამრავლება: პირველი მრავალწევრის **ყოველი** წევრი მრავლდება მეორის **ყოველ** წევრზე:
$$(a+b)(c+d)=ac+ad+bc+bd.$$
:::

:::theorem
ორი არანულოვანი მრავალწევრის ნამრავლის ხარისხი მათი ხარისხების ჯამის ტოლია.
:::

:::formula სასარგებლო მნიშვნელობები
$P(1)$ არის $P$-ს კოეფიციენტების ჯამი, ხოლო $P(0)$ — თავისუფალი წევრი.
:::

## დამტკიცება

ვთქვათ $P(x)=a_nx^n+\ldots$ და $Q(x)=b_mx^m+\ldots$, სადაც $a_n\neq0$, $b_m\neq0$. ნამრავლში უმაღლესი ხარისხი $x^{n+m}$ მიიღება მხოლოდ ერთი გზით — $a_nx^n\cdot b_mx^m$. სხვა ყველა ნამრავლის ხარისხი ნაკლებია. ამიტომ $x^{n+m}$-ის კოეფიციენტია $a_nb_m\neq0$ — ის არ შეიძლება გაქრეს. ნამრავლის ხარისხი ზუსტად $n+m$-ია. $\blacksquare$

**$P(1)$-ის თვისება:** $P(1)=a_n\cdot1^n+\ldots+a_1\cdot1+a_0=a_n+\ldots+a_1+a_0$.

## ამოხსნილი მაგალითები

:::example მარტივი
გაამარტივეთ $(3x^2-2x+1)-(x^2+4x-5)$.
:::solution
მინუსი მეორე ფრჩხილის ყველა წევრის ნიშანს ცვლის:
$$3x^2-2x+1-x^2-4x+5=2x^2-6x+6.$$
**პასუხი:** $2x^2-6x+6$.
:::
:::

:::example საშუალო
გაამრავლეთ $(2x-3)(x^2+x-4)$.
:::solution
$$2x\cdot(x^2+x-4)=2x^3+2x^2-8x,\qquad -3\cdot(x^2+x-4)=-3x^2-3x+12.$$
შევკრიბოთ: $2x^3-x^2-11x+12$.

შემოწმება $x=1$-ზე: $(2-3)(1+1-4)=2$ და $2-1-11+12=2$.

**პასუხი:** $2x^3-x^2-11x+12$.
:::
:::

:::example რთული
$P(x)=(1+x)(1+2x)(1+3x)(1+4x)$. იპოვეთ $x^2$-ის კოეფიციენტი და ყველა კოეფიციენტის ჯამი, ფრჩხილების სრულად გახსნის გარეშე.
:::solution
$x^2$ მიიღება, როცა ოთხი ფრჩხილიდან ორიდან ვიღებთ $x$-იან წევრს, დანარჩენი ორიდან — $1$-ს. ამიტომ კოეფიციენტი არის $1,2,3,4$ რიცხვების წყვილ-წყვილად ნამრავლების ჯამი:
$$1\cdot2+1\cdot3+1\cdot4+2\cdot3+2\cdot4+3\cdot4=2+3+4+6+8+12=35.$$
კოეფიციენტების ჯამი: $P(1)=2\cdot3\cdot4\cdot5=120$.

**პასუხი:** $35$ და $120$.
:::
:::

## გავრცელებული შეცდომები

- **მაჩვენებლების შეკრება შეკრებისას.** $x^2+x^2=2x^2$, და არა $x^4$. მაჩვენებლები იკრიბება მხოლოდ გამრავლებისას: $x^2\cdot x^2=x^4$.
- **მინუსი ფრჩხილის წინ.** $-(x^2+4x-5)=-x^2-4x+5$: ნიშანი იცვლება **ყველა** წევრში, ბოლოსიც.
- **ერთწევრის ხარისხი.** $5x^2y^3$-ის ხარისხია $5$ (და არა $3$ ან $2$).
- **„შუა წევრების“ დაკარგვა.** $(a+b)(c+d)$-ში ოთხი ნამრავლია; ხშირად ავიწყდებათ $ad$ ან $bc$.

## შეამოწმე თავი

:::check
რისი ტოლია $-4a^3b^2c$ ერთწევრის ხარისხი?
:::answer
$3+2+1=6$.
:::
:::

:::check
იპოვეთ $x^2-3x+2$-ის მნიშვნელობა, როცა $x=-1$.
:::answer
$1+3+2=6$.
:::
:::

:::check
იპოვეთ $(2x-1)^{10}$ მრავალწევრის კოეფიციენტების ჯამი.
:::answer
კოეფიციენტების ჯამი არის $P(1)=(2-1)^{10}=1$.
:::
:::
