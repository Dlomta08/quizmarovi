## მთავარი იდეა

ფუნქცია წერტილში უწყვეტია, თუ მისი ზღვარი ამ წერტილში მის მნიშვნელობას ემთხვევა: გრაფიკს იქ „წყვეტა“ არ აქვს. ყველა ელემენტარული ფუნქცია (მრავალწევრი, ფესვი, ხარისხი, ლოგარითმი, ტრიგონომეტრიული) უწყვეტია თავის განსაზღვრის არეზე.

უწყვეტ ფუნქციას ორი ძლიერი თვისება აქვს: ნიშნის შეცვლისას ის ნულზე გადის (ბოლცანო–კოში), და ჩაკეტილ შუალედზე უდიდეს და უმცირეს მნიშვნელობას აღწევს (ვაიერშტრასი). პირველი არის შუალედების მეთოდის საფუძველი.

## განმარტებები და ფორმულები

:::definition
$f$ უწყვეტია $a$ წერტილში, თუ
$$\lim_{x\to a}f(x)=f(a).$$
ეს ნიშნავს სამ რამეს: $f(a)$ არსებობს, ზღვარი არსებობს და ისინი ტოლია.
:::

:::definition წყვეტის წერტილები
- **აცილებადი:** ზღვარი არსებობს, მაგრამ $f(a)$-ს არ უდრის (ან $f(a)$ არ არის განსაზღვრული).
- **პირველი გვარის (ნახტომი):** ცალმხრივი ზღვრები სასრულია, მაგრამ სხვადასხვაა.
- **მეორე გვარის:** ერთი ცალმხრივი ზღვარი მაინც უსასრულოა ან არ არსებობს.
:::

:::theorem ბოლცანო–კოშის თეორემა
თუ $f$ უწყვეტია $[a,b]$-ზე და $f(a)\cdot f(b)<0$, მაშინ არსებობს $c\in(a,b)$, რომ $f(c)=0$. ზოგადად: უწყვეტი ფუნქცია იღებს ყველა მნიშვნელობას $f(a)$-სა და $f(b)$-ს შორის.
:::

:::theorem ვაიერშტრასის თეორემა
$[a,b]$-ზე უწყვეტი ფუნქცია შემოსაზღვრულია და აღწევს თავის უდიდეს და უმცირეს მნიშვნელობებს.
:::

## რატომ მუშაობს

**ბოლცანო–კოში (შუაზე გაყოფით).** ვთქვათ $f(a)<0<f(b)$. ავიღოთ შუაწერტილი $m$. თუ $f(m)=0$ — მზადაა; თუ არა, ავირჩიოთ ის ნახევარი, რომლის ბოლოებზე ნიშნები განსხვავდება. ასე ვიღებთ ჩადგმული შუალედების მიმდევრობას, რომელთა სიგრძე $\dfrac{b-a}{2^n}\to0$. ისინი ერთ $c$ წერტილს „იჭერენ“. უწყვეტობის გამო $f(c)$ არ შეიძლება იყოს არც დადებითი, არც უარყოფითი — $f(c)=0$. $\blacksquare$

ამიტომ შუალედების მეთოდში უწყვეტი ფუნქცია ნიშანს მხოლოდ ნულებსა და წყვეტის წერტილებში იცვლის.

## ამოხსნილი მაგალითები

:::example მარტივი
რა $a$-სთვის არის უწყვეტი $f(x)=\begin{cases}x^2+1,&x\le1\\ ax-3,&x>1\end{cases}$?
:::solution
$x=1$-ში: მარცხნიდან და $f(1)$: $2$; მარჯვნიდან: $a-3$. $a-3=2$, $a=5$.

**პასუხი:** $a=5$.
:::
:::

:::example საშუალო
დაადგინეთ $f(x)=\dfrac{x^2-1}{x^2-x}$-ის წყვეტის წერტილები და მათი გვარი.
:::solution
$f(x)=\dfrac{(x-1)(x+1)}{x(x-1)}$, განუსაზღვრელია $x=0$-სა და $x=1$-ში.

$x=1$: $f(x)=\dfrac{x+1}{x}\to2$ — აცილებადი წყვეტა.

$x=0$: $\dfrac{x+1}{x}\to\pm\infty$ — მეორე გვარის წყვეტა.

**პასუხი:** $x=1$ აცილებადი, $x=0$ მეორე გვარის.
:::
:::

:::example რთული
$f$ უწყვეტია $[0,1]$-ზე და $f(0)=f(1)$. დაამტკიცეთ, რომ არსებობს $x\in\left[0,\frac12\right]$, რომ $f\left(x+\frac12\right)=f(x)$.
:::solution
განვიხილოთ $g(x)=f\left(x+\frac12\right)-f(x)$, უწყვეტია $\left[0,\frac12\right]$-ზე.
$$g(0)+g\left(\tfrac12\right)=f\left(\tfrac12\right)-f(0)+f(1)-f\left(\tfrac12\right)=f(1)-f(0)=0.$$
ე.ი. $g(0)$ და $g\left(\frac12\right)$ ან ორივე $0$-ია, ან სხვადასხვა ნიშნისაა. მეორე შემთხვევაში ბოლცანო–კოშით $g$ სადღაც ნულდება. ორივე შემთხვევაში $g(x)=0$ რომელიმე $x$-ისთვის. $\blacksquare$

(ანუ გრაფიკს აქვს $\frac12$ სიგრძის ჰორიზონტალური ქორდა.)
:::
:::

## გავრცელებული შეცდომები

- **მხოლოდ ზღვრის შემოწმება.** უწყვეტობისთვის ზღვარი $f(a)$-ს უნდა უდრიდეს; $f(a)$ უნდა არსებობდეს.
- **ბოლცანო–კოში წყვეტილ ფუნქციაზე.** $\dfrac1x$-ს $[-1,1]$-ზე ნიშანი ეცვლება, მაგრამ ნული არ აქვს — ის $0$-ში წყვეტილია.
- **ნიშნის შეცვლის გარეშე ფესვი არ არის.** $x^2$-ს $0$-ში ფესვი აქვს, თუმცა ნიშანს არ იცვლის. თეორემა საკმარის პირობას იძლევა, არა აუცილებელს.

## შეამოწმე თავი

:::check
რისი ტოლი უნდა იყოს $f(0)$, რომ $f(x)=\dfrac{\sin x}{x}$ უწყვეტი იყოს $0$-ში?
:::answer
$1$.
:::
:::

:::check
დაამტკიცეთ, რომ $x^5-3x+1=0$-ს სამი ნამდვილი ფესვი მაინც აქვს.
:::answer
$f(-2)=-25<0$, $f(0)=1>0$, $f(1)=-1<0$, $f(2)=27>0$. სამი ნიშნის შეცვლა — ფესვი $(-2,0)$, $(0,1)$, $(1,2)$ შუალედებში.
:::
:::

:::check
რა გვარის წყვეტა აქვს $\operatorname{sign}x$-ს $0$-ში?
:::answer
პირველი გვარის (ნახტომი $-1$-დან $1$-მდე).
:::
:::
