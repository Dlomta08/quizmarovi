## მთავარი იდეა

ამოცანაში შეიძლება შემოიღონ ახალი მოქმედება, მაგალითად $a*b=2a-b$. ეს უბრალოდ წესია: რა გავაკეთოთ ორ რიცხვთან. ასეთი ამოცანები ამოწმებს, რამდენად ზუსტად ვიყენებთ განმარტებას. მთავარია არ „მივანიჭოთ“ ახალ მოქმედებას ჩვეულებრივი შეკრების ან გამრავლების თვისებები, სანამ არ დავამტკიცებთ.

ოლიმპიადურ ამოცანებში ხშირად საჭიროა ბევრი ოპერაციის თანმიმდევრული გამოთვლა. ასეთ დროს ეძებენ „ფარულ სტრუქტურას“: ჩანაწერს, რომელშიც ახალი ოპერაცია ძველ, ნაცნობ მოქმედებად გადაიქცევა.

## განმარტებები და ფორმულები

:::definition
**ბინარული ოპერაცია** $*$ ყოველ $(a,b)$ წყვილს უთანადებს ერთ რიცხვს $a*b$-ს. მნიშვნელობის გამოსათვლელად $a$ და $b$ ზუსტად თავის ადგილზე ჩავსვამთ წესში.
:::

:::definition თვისებები
- **კომუტატიურობა:** $a*b=b*a$ ყოველი $a,b$-სთვის.
- **ასოციაციურობა:** $(a*b)*c=a*(b*c)$ ყოველი $a,b,c$-სთვის.
- **ნეიტრალური ელემენტი** $e$: $a*e=e*a=a$ ყოველი $a$-სთვის.
:::

:::formula როგორ ვიმოქმედოთ
1. ზუსტად წაიკითხეთ წესი და დაადგინეთ, რომელი რიცხვი რომელ ადგილზეა.
2. ფრჩხილები ყოველთვის **შიგნიდან** გამოთვალეთ: ჯერ შიდა ოპერაცია, მერე გარე.
3. განტოლებაში $x*a=b$ ჯერ $x*a$ ჩაწერეთ ჩვეულებრივი გამოსახულებით, შემდეგ ამოხსენით.
4. თუ საჭიროა ბევრი ოპერაციის გამოთვლა, ეძებეთ ფორმულა, რომელიც ოპერაციას ჩვეულებრივ მოქმედებად აქცევს.
:::

:::note
თვისების **დასამტკიცებლად** საჭიროა ზოგადი გამოთვლა ასოებით. მის **უარსაყოფად** საკმარისია ერთი კონტრმაგალითი.
:::

:::theorem
ოპერაცია $a\circ b=a+b+ab$ კომუტატიური და ასოციაციურია, ნეიტრალური ელემენტია $0$, და
$$a\circ b=(a+1)(b+1)-1.$$
:::

## დამტკიცება

ტოლობა $(a+1)(b+1)-1=ab+a+b+1-1=a+b+ab$ პირდაპირ გამრავლებით მოწმდება.

ახლა ეს ჩანაწერი გამოვიყენოთ. აღვნიშნოთ $\varphi(x)=x+1$. მაშინ $\varphi(a\circ b)=\varphi(a)\,\varphi(b)$: ოპერაცია $\circ$ „ჩვეულებრივ გამრავლებად იქცევა“, თუ ყოველ რიცხვს $1$-ს დავუმატებთ. ამიტომ
$$(a\circ b)\circ c=(a+1)(b+1)(c+1)-1=a\circ(b\circ c),$$
რადგან ჩვეულებრივი გამრავლება ასოციაციურია. კომუტატიურობა ჩანს ფორმულიდან. ბოლოს, $a\circ0=a+0+0=a$. $\blacksquare$

## ამოხსნილი მაგალითები

:::example მარტივი
$a*b=2a-b$. გამოთვალეთ $(3*1)*4$ და $3*(1*4)$. ასოციაციურია თუ არა $*$?
:::solution
$3*1=6-1=5$, ამიტომ $(3*1)*4=5*4=10-4=6$.

$1*4=2-4=-2$, ამიტომ $3*(1*4)=3*(-2)=6+2=8$.

$6\neq8$ — ეს კონტრმაგალითია.

**პასუხი:** $6$ და $8$; ოპერაცია არ არის ასოციაციური.
:::
:::

:::example საშუალო
$a\circ b=a+b+ab$. ამოხსენით განტოლება $x\circ2=11$.
:::solution
$x\circ2=x+2+2x=3x+2$. $3x+2=11$, $x=3$.

შემოწმება: $3\circ2=3+2+6=11$.

**პასუხი:** $x=3$.
:::
:::

:::example რთული
$a\circ b=a+b+ab$. გამოთვალეთ $1\circ2\circ3\circ\ldots\circ10$.
:::solution
ოპერაცია ასოციაციურია, ამიტომ ფრჩხილების განლაგება მნიშვნელობას არ ცვლის. თეორემის ფორმულა ბევრ რიცხვზეც ვრცელდება:
$$a_1\circ a_2\circ\ldots\circ a_n=(a_1+1)(a_2+1)\cdots(a_n+1)-1.$$
ამიტომ პასუხია
$$2\cdot3\cdots11-1=11!-1=39\,916\,800-1=39\,916\,799.$$
**პასუხი:** $39\,916\,799$.
:::
:::

## გავრცელებული შეცდომები

- **თვისებების „ავტომატურად“ გამოყენება.** $a*b=2a-b$ არც კომუტატიურია ($1*2=0$, $2*1=3$) და არც ასოციაციური. ფრჩხილები აქ მნიშვნელოვანია.
- **ადგილების არევა.** $a*b$-ში $a$ პირველ ადგილზეა. $3*(-2)$-ში $a=3$, $b=-2$: $2\cdot3-(-2)=8$.
- **ნიშნის შეცდომა ჩასმისას.** უარყოფითი რიცხვი ყოველთვის ფრჩხილებში ჩასვით.
- **ერთი მაგალითით „დამტკიცება“.** თუ $2*3=3*2$ ერთ წყვილზე სრულდება, ეს კომუტატიურობას არ ამტკიცებს.

## შეამოწმე თავი

:::check
$a\triangle b=a^2-b$. გამოთვალეთ $3\triangle4$.
:::answer
$9-4=5$.
:::
:::

:::check
კომუტატიურია თუ არა $a*b=2a-b$?
:::answer
არა: $1*2=0$, ხოლო $2*1=3$.
:::
:::

:::check
იპოვეთ $a\circ b=a+b+ab$ ოპერაციის ნეიტრალური ელემენტი.
:::answer
$a+e+ae=a\iff e(1+a)=0$ ყოველი $a$-სთვის, ამიტომ $e=0$.
:::
:::
