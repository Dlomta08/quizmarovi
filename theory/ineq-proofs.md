## მთავარი იდეა

უტოლობის დამტკიცება ნიშნავს, რომ ის ცვლადების **ყველა** დასაშვები მნიშვნელობისთვის სრულდება. ყველაზე ძლიერი ფაქტი ძალიან მარტივია: კვადრატი არაუარყოფითია. ბევრი უტოლობა ამიტომ სხვაობის კვადრატების ჯამად ჩაწერით მტკიცდება. სხვა ხერხებია ცნობილი უტოლობების გამოყენება და შესაკრებების შეფასება ისეთი გამოსახულებებით, რომელთა ჯამიც ადვილად ითვლება.

## განმარტებები და ფორმულები

:::theorem საბაზისო უტოლობა
ნებისმიერი ნამდვილი $x$-ისთვის $x^2\ge0$; ტოლობა მხოლოდ $x=0$-ზე. აქედან
$$a^2+b^2\ge2ab,\qquad a^2+b^2+c^2\ge ab+bc+ca.$$
:::

:::formula დამტკიცების ხერხები
1. **სხვაობის მეთოდი:** ვამტკიცებთ $A-B\ge0$, ხშირად $A-B$-ს კვადრატების ჯამად ჩაწერით.
2. **ცნობილი უტოლობებიდან გამოყვანა:** ვკრებთ ან ვამრავლებთ (დადებით) უტოლობებს.
3. **შეფასება:** შესაკრებებს ვცვლით უფრო დიდით (ან პატარათი), რომელთა ჯამი ადვილად ითვლება — მაგალითად, ტელესკოპურად.
4. **ტოლფასი გარდაქმნები:** უტოლობიდან ვიწყებთ და მივდივართ ცხადამდე — მხოლოდ შექცევადი ნაბიჯებით.
:::

:::theorem კოში-ბუნიაკოვსკის უტოლობა (ორი წყვილისთვის)
$$(a^2+b^2)(c^2+d^2)\ge(ac+bd)^2.$$
:::

## დამტკიცება

$a^2+b^2-2ab=(a-b)^2\ge0$.

$$a^2+b^2+c^2-ab-bc-ca=\frac12\left[(a-b)^2+(b-c)^2+(c-a)^2\right]\ge0.$$
ტოლობა სრულდება მხოლოდ $a=b=c$-ზე.

კოში-ბუნიაკოვსკი: იგივეობით $(a^2+b^2)(c^2+d^2)=(ac+bd)^2+(ad-bc)^2$, ხოლო $(ad-bc)^2\ge0$. $\blacksquare$

## ამოხსნილი მაგალითები

:::example მარტივი
დაამტკიცეთ, რომ $a+\dfrac1a\ge2$ ყოველი $a>0$-სთვის.
:::solution
$$a+\frac1a-2=\frac{a^2-2a+1}{a}=\frac{(a-1)^2}{a}\ge0,$$
რადგან მრიცხველი არაუარყოფითია, მნიშვნელი დადებითი. ტოლობა: $a=1$. $\blacksquare$
:::
:::

:::example საშუალო
დაამტკიცეთ, რომ $x^2+y^2+1\ge xy+x+y$.
:::solution
ეს არის $a^2+b^2+c^2\ge ab+bc+ca$, სადაც $a=x$, $b=y$, $c=1$. პირდაპირაც:
$$2(x^2+y^2+1-xy-x-y)=(x-y)^2+(x-1)^2+(y-1)^2\ge0.$$
ტოლობა: $x=y=1$. $\blacksquare$
:::
:::

:::example რთული
დაამტკიცეთ, რომ ყოველი $n\ge2$-ისთვის
$$\frac1{2^2}+\frac1{3^2}+\ldots+\frac1{n^2}<1.$$
:::solution
შევაფასოთ ყოველი შესაკრები: $k\ge2$-ისთვის
$$\frac1{k^2}<\frac1{(k-1)k}=\frac1{k-1}-\frac1k.$$
შევკრიბოთ $k=2,\ldots,n$:
$$\sum_{k=2}^n\frac1{k^2}<\left(1-\frac12\right)+\left(\frac12-\frac13\right)+\ldots+\left(\frac1{n-1}-\frac1n\right)=1-\frac1n<1.\ \blacksquare$$
:::
:::

## გავრცელებული შეცდომები

- **„დამტკიცება“ ბოლოდან.** თუ $A\ge B$-დან მივედით ჭეშმარიტ $0\le(a-b)^2$-მდე, ყველა ნაბიჯი უნდა იყოს შექცევადი. თორემ ცრუ უტოლობაც „დამტკიცდება“.
- **უარყოფითზე გამრავლება/გაყოფა.** $a+\frac1a\ge2$ არ სრულდება $a<0$-სთვის: $a=-1$ იძლევა $-2$.
- **კვადრატში აყვანა ნიშნის შემოწმების გარეშე.** ორივე მხარე არაუარყოფითი უნდა იყოს.
- **რიცხვებით შემოწმება.** რამდენიმე მნიშვნელობაზე შემოწმება დამტკიცება არ არის.

## შეამოწმე თავი

:::check
როდის სრულდება ტოლობა $a+\dfrac1a\ge2$-ში ($a>0$)?
:::answer
მხოლოდ $a=1$-ზე.
:::
:::

:::check
დაამტკიცეთ, რომ $x^2-x+1>0$ ყოველი $x$-სთვის.
:::answer
$x^2-x+1=\left(x-\frac12\right)^2+\frac34\ge\frac34>0$.
:::
:::

:::check
მართალია თუ არა, რომ $a^2+b^2\ge2ab$ უარყოფითი $a$ და $b$-სთვისაც?
:::answer
კი: $(a-b)^2\ge0$ ყველა ნამდვილი რიცხვისთვის სრულდება.
:::
:::
