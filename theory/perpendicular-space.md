## მთავარი იდეა

წრფე სიბრტყის მართობულია, თუ ის მართობულია სიბრტყის **ყველა** წრფის. შესამოწმებლად საკმარისია ორი გადამკვეთი წრფე.

სტერეომეტრიის მთავარი ინსტრუმენტია **სამი მართობის თეორემა**: ის სივრცის მართობულობას ბრტყელ მართობულობაზე დაიყვანს — დახრილი მართობულია სიბრტყის წრფის ⟺ მისი პროექცია მართობულია ამ წრფის.

## განმარტებები და ფორმულები

:::theorem მართობულობის ნიშანი
თუ წრფე მართობულია სიბრტყის ორი გადამკვეთი წრფის, ის სიბრტყის მართობულია.
:::

:::definition მართობი და დახრილი
$P\notin\alpha$. $PH\perp\alpha$ ($H\in\alpha$) — **მართობი**, $H$ — მისი ფუძე. $PA$ ($A\in\alpha$, $A\ne H$) — **დახრილი**, $HA$ — დახრილის **პროექცია**. $PA^2=PH^2+HA^2$.
:::

:::formula დახრილების თვისებები
- მართობი ყოველ დახრილზე მოკლეა.
- ტოლ დახრილებს ტოლი პროექციები აქვს და პირიქით.
- დიდ დახრილს დიდი პროექცია აქვს.
:::

:::theorem სამი მართობის თეორემა
$a\subset\alpha$. $a\perp PA$ (დახრილი) ⟺ $a\perp HA$ (პროექცია).
:::

:::theorem სიბრტყეების მართობულობა
თუ სიბრტყე შეიცავს მეორე სიბრტყის მართობ წრფეს, სიბრტყეები ურთიერთმართობულია.
:::

## დამტკიცება

**სამი მართობი.** ვთქვათ $a\perp HA$. ამასთან $a\perp PH$, რადგან $PH\perp\alpha$. მაშინ $a$ მართობულია $PAH$ სიბრტყის ორი გადამკვეთი წრფის ($HA$, $PH$), ე.ი. მთელი სიბრტყის — და მათ შორის $PA$-ს.

შებრუნებული: თუ $a\perp PA$ და $a\perp PH$, მაშინ $a\perp(PAH)$, ამიტომ $a\perp HA$. $\blacksquare$

**დახრილები.** $PHA$ მართკუთხა სამკუთხედია, $PA^2=PH^2+HA^2$, და $PH$ ფიქსირებულია. ამიტომ $PA$ და $HA$ ერთად იზრდება და ერთად არის ტოლი.

## ამოხსნილი მაგალითები

:::example მარტივი
წერტილი სიბრტყიდან $12$-ითაა დაშორებული, მისგან გავლებული დახრილი $13$-ია. იპოვეთ პროექცია.
:::solution
$\sqrt{169-144}=5$.

**პასუხი:** $5$.
:::
:::

:::example საშუალო
წერტილიდან სიბრტყეზე გავლებულია ორი დახრილი, $10$ და $17$. მათი პროექციები შეეფარდება როგორც $2:5$. იპოვეთ მანძილი წერტილიდან სიბრტყემდე.
:::solution
პროექციები $2x$ და $5x$. $h^2=100-4x^2=289-25x^2$, $21x^2=189$, $x=3$.

$h^2=100-36=64$, $h=8$.

**პასუხი:** $8$.
:::
:::

:::example რთული
$ABCD$ კვადრატის გვერდი $6\sqrt2$-ია, $SA\perp(ABC)$, $SA=8$. იპოვეთ მანძილი $S$-დან $BD$ წრფემდე.
:::solution
$O$ — დიაგონალების გადაკვეთა. კვადრატში $AO\perp BD$, $AO=\dfrac{AC}{2}=\dfrac{12}{2}=6$.

$AO$ არის $SO$ დახრილის პროექცია. სამი მართობის თეორემით $SO\perp BD$, ამიტომ საძიებელი მანძილი $SO$-ა:
$$SO=\sqrt{SA^2+AO^2}=\sqrt{64+36}=10.$$

**პასუხი:** $10$.
:::
:::

## გავრცელებული შეცდომები

- **ერთი წრფის მართობი.** წრფე, რომელიც სიბრტყის **ერთი** წრფის მართობულია, სიბრტყის მართობული სულაც არ არის. საჭიროა ორი გადამკვეთი.
- **სამი მართობი სხვა სიბრტყეში.** $a$ წრფე უნდა მდებარეობდეს **იმ სიბრტყეში**, რომელზეც პროექცია იგება.
- **ნახაზზე მართი კუთხე.** სივრცით ნახაზზე მართი კუთხე ხშირად მართად არ ჩანს — ენდეთ დამტკიცებას, არა თვალს.

## შეამოწმე თავი

:::check
$SA\perp(ABC)$, $\angle C=90^\circ$. დაამტკიცეთ, რომ $BC\perp SC$.
:::answer
$AC$ არის $SC$-ს პროექცია და $BC\perp AC$. სამი მართობის თეორემით $BC\perp SC$.
:::
:::

:::check
წერტილიდან სიბრტყეზე გავლებული ორი დახრილის პროექციები ტოლია. რა შეგვიძლია ვთქვათ დახრილებზე?
:::answer
ისინი ტოლია.
:::
:::

:::check
$S$ წერტილი ტოლი მანძილითაა დაშორებული სამკუთხედის წვეროებიდან. სად ეცემა $S$-დან სამკუთხედის სიბრტყეზე დაშვებული მართობი?
:::answer
შემოხაზული წრეწირის ცენტრში: ტოლ დახრილებს ტოლი პროექციები აქვს.
:::
:::
