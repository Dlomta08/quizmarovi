## მთავარი იდეა

ფუნქცია არის წესი, რომელიც ყოველ დასაშვებ $x$-ს ზუსტად ერთ $y$-ს უთანადებს. მთავარი სიტყვაა „ზუსტად ერთს“: ერთ $x$-ს ორი სხვადასხვა მნიშვნელობა ვერ ექნება. ფუნქციის შესწავლა ყოველთვის იწყება ორი კითხვით: რა $x$-ების ჩასმა შეიძლება (განსაზღვრის არე) და რა მნიშვნელობებს იღებს ის (მნიშვნელობათა სიმრავლე).

## განმარტებები და ფორმულები

:::definition
**ფუნქცია** $f$ არის წესი, რომელიც $D$ სიმრავლის ყოველ $x$ ელემენტს უთანადებს ერთადერთ რიცხვს $f(x)$-ს. $x$ — არგუმენტი (დამოუკიდებელი ცვლადი), $y=f(x)$ — ფუნქციის მნიშვნელობა.
:::

:::definition
**განსაზღვრის არე** $D(f)$ — ყველა $x$, რომლისთვისაც $f(x)$ განსაზღვრულია. **მნიშვნელობათა სიმრავლე** $E(f)$ — ყველა მნიშვნელობა, რომელსაც $f$ იღებს: $E(f)=\{f(x):x\in D(f)\}$.
:::

:::formula განსაზღვრის არის პოვნა (თუ არე მოცემული არ არის)
- მნიშვნელი $\neq0$;
- ლუწი ხარისხის ფესვის ქვეშ $\ge0$;
- ლოგარითმის ქვეშ $>0$, ფუძე $>0$ და $\neq1$;
- $\operatorname{tg}x$: $x\neq\frac\pi2+\pi k$.
ყველა პირობის თანაკვეთა არის $D(f)$.
:::

:::definition
ფუნქციის **გრაფიკი** არის სიბრტყის ყველა $(x;f(x))$ წერტილის სიმრავლე, სადაც $x\in D(f)$. **ვერტიკალური წრფის ტესტი:** წირი რაიმე ფუნქციის გრაფიკია მაშინ და მხოლოდ მაშინ, როცა ყოველი ვერტიკალური წრფე მას არაუმეტეს ერთ წერტილში კვეთს.
:::

:::formula მნიშვნელობათა სიმრავლის პოვნა
$a\in E(f)$ ნიშნავს, რომ განტოლებას $f(x)=a$ აქვს ამონახსნი $D(f)$-ში. ამიტომ ვხსნით $f(x)=a$-ს $x$-ის მიმართ და ვადგენთ, რომელი $a$-სთვის არსებობს ამონახსნი.
:::

## რატომ მუშაობს

ვერტიკალური წრფის ტესტი პირდაპირ განმარტებიდან გამოდის. წრფე $x=x_0$ გრაფიკს კვეთს $(x_0;y)$ წერტილებში, სადაც $y$ არის $x_0$-ის შესაბამისი მნიშვნელობა. ფუნქციას ყოველ $x_0$-ზე ერთი მნიშვნელობა აქვს — ამიტომ გადაკვეთის წერტილიც ერთია (ან არც ერთი, თუ $x_0\notin D(f)$). მაგალითად, წრეწირი $x^2+y^2=1$ ფუნქციის გრაფიკი არ არის: წრფე $x=0$ მას ორ წერტილში კვეთს.

მნიშვნელობათა სიმრავლის ხერხიც განმარტებაა: $a$ არის მნიშვნელობა, თუ რომელიმე $x$-ისთვის $f(x)=a$.

## ამოხსნილი მაგალითები

:::example მარტივი
იპოვეთ $f(x)=\dfrac{\sqrt{x+2}}{x-3}$ ფუნქციის განსაზღვრის არე.
:::solution
$x+2\ge0$ და $x-3\neq0$, ანუ $x\ge-2$, $x\neq3$.

**პასუხი:** $D(f)=[-2;\,3)\cup(3;\,+\infty)$.
:::
:::

:::example საშუალო
იპოვეთ $f(x)=x^2-4x+7$ ფუნქციის მნიშვნელობათა სიმრავლე.
:::solution
სრული კვადრატი: $f(x)=(x-2)^2+3$. $(x-2)^2$ იღებს ყველა არაუარყოფით მნიშვნელობას, ამიტომ $f(x)$ იღებს ყველა მნიშვნელობას $3$-დან ზემოთ.

**პასუხი:** $E(f)=[3;\,+\infty)$.
:::
:::

:::example რთული
იპოვეთ $f(x)=\dfrac{x}{x^2+1}$ ფუნქციის მნიშვნელობათა სიმრავლე.
:::solution
$a\in E(f)\iff$ განტოლებას $\frac{x}{x^2+1}=a$ აქვს ამონახსნი, ანუ $ax^2-x+a=0$.

- $a=0$: $x=0$ — ამონახსნი არის.
- $a\neq0$: კვადრატული განტოლებისთვის საჭიროა $D=1-4a^2\ge0$, ანუ $-\frac12\le a\le\frac12$.

**პასუხი:** $E(f)=\left[-\dfrac12;\,\dfrac12\right]$.
:::
:::

## გავრცელებული შეცდომები

- **$D(f)$-ში ერთი პირობის დავიწყება.** $\frac{\sqrt{x+2}}{x-3}$-ში ორივე პირობაა საჭირო: ფესვისაც და მნიშვნელისაც.
- **$E(f)$-ის „გამოცნობა“ რამდენიმე მნიშვნელობით.** ცხრილიდან მნიშვნელობათა სიმრავლე არ დგინდება — საჭიროა განტოლება $f(x)=a$ ან შეფასება.
- **გამარტივება $D(f)$-ის პოვნამდე.** $\frac{x^2-1}{x-1}$-ის განსაზღვრის არეში $1$ არ შედის, თუმცა გამარტივებით მიიღება $x+1$.
- **„ფუნქცია = ფორმულა“.** ფუნქცია შეიძლება მოცემული იყოს ცხრილით, გრაფიკით ან სიტყვიერად; ერთ ფუნქციას სხვადასხვა შუალედზე სხვადასხვა ფორმულა შეიძლება ჰქონდეს.

## შეამოწმე თავი

:::check
$f(x)=2x^2-3$. იპოვეთ $f(-2)$.
:::answer
$2\cdot4-3=5$.
:::
:::

:::check
იპოვეთ $f(x)=\dfrac{1}{\sqrt{4-x^2}}$ ფუნქციის განსაზღვრის არე.
:::answer
$4-x^2>0$, ანუ $x\in(-2;\,2)$.
:::
:::

:::check
არის თუ არა წრეწირი $x^2+y^2=1$ რომელიმე ფუნქციის $y=f(x)$ გრაფიკი?
:::answer
არა: მაგალითად, წრფე $x=0$ მას ორ წერტილში კვეთს — $(0;1)$ და $(0;-1)$.
:::
:::
