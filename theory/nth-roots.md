## მთავარი იდეა

$n$-ური ხარისხის ფესვი $n$-ურ ხარისხში აყვანის საპირისპირო მოქმედებაა. კენტი $n$-ისთვის ფესვი ნებისმიერი რიცხვიდან არსებობს, ლუწისთვის — მხოლოდ არაუარყოფითიდან. ფესვი შეიძლება ჩავწეროთ წილადი მაჩვენებლით: $\sqrt[n]{a}=a^{1/n}$. ასე ფესვებთან მუშაობა ხარისხის ნაცნობ წესებზე დადის.

## განმარტებები და ფორმულები

:::definition
ნატურალური $n\ge2$-ისთვის:
- თუ $n$ **ლუწია** და $a\ge0$, $\sqrt[n]a$ არის ის არაუარყოფითი რიცხვი, რომლის $n$-ური ხარისხი $a$-ა;
- თუ $n$ **კენტია**, $\sqrt[n]a$ არის ის (ერთადერთი) რიცხვი, რომლის $n$-ური ხარისხი $a$-ა. მაგალითად $\sqrt[3]{-8}=-2$.
:::

:::theorem თვისებები
$a,b\ge0$-ისთვის და ნატურალური $n,k$-სთვის:
$$\sqrt[n]{ab}=\sqrt[n]a\,\sqrt[n]b,\qquad \sqrt[n]{\frac ab}=\frac{\sqrt[n]a}{\sqrt[n]b}\ (b>0),\qquad \sqrt[k]{\sqrt[n]a}=\sqrt[nk]a,\qquad \sqrt[nk]{a^k}=\sqrt[n]a.$$
ასევე $\sqrt[n]{a^n}=|a|$ ლუწი $n$-ისთვის და $\sqrt[n]{a^n}=a$ კენტი $n$-ისთვის.
:::

:::definition რაციონალური მაჩვენებელი
$a>0$, მთელი $m$ და ნატურალური $n$-ისთვის
$$a^{\frac mn}=\sqrt[n]{a^m}=\left(\sqrt[n]a\right)^m.$$
ასეთი ხარისხისთვის სრულდება ყველა ჩვეული წესი: $a^ra^s=a^{r+s}$, $(a^r)^s=a^{rs}$, $(ab)^r=a^rb^r$.
:::

## დამტკიცება

**ნამრავლის ფესვი.** $a,b\ge0$. რიცხვი $\sqrt[n]a\,\sqrt[n]b$ არაუარყოფითია და მისი $n$-ური ხარისხია
$$\left(\sqrt[n]a\right)^n\left(\sqrt[n]b\right)^n=ab.$$
არაუარყოფითი რიცხვი, რომლის $n$-ური ხარისხი $ab$-ა, ერთადერთია (არაუარყოფით რიცხვებზე $x\mapsto x^n$ მკაცრად ზრდადია). ამიტომ ის $\sqrt[n]{ab}$-ს ემთხვევა. $\blacksquare$

**განმარტების სისწორე.** $a^{m/n}$ არ უნდა იყოს დამოკიდებული წილადის ჩანაწერზე: $\frac mn=\frac{mk}{nk}$. ბოლო თვისებით $\sqrt[nk]{a^{mk}}=\sqrt[n]{a^m}$, ანუ ორივე ჩანაწერი ერთსა და იმავე რიცხვს იძლევა.

## ამოხსნილი მაგალითები

:::example მარტივი
გამოთვალეთ $27^{2/3}$ და $16^{-3/4}$.
:::solution
$27^{2/3}=\left(\sqrt[3]{27}\right)^2=3^2=9$.

$16^{-3/4}=\dfrac{1}{\left(\sqrt[4]{16}\right)^3}=\dfrac1{2^3}=\dfrac18$.

**პასუხი:** $9$ და $\dfrac18$.
:::
:::

:::example საშუალო
გაამარტივეთ $\dfrac{a^{1/2}\cdot a^{1/3}}{a^{-1/6}}$, სადაც $a>0$.
:::solution
$$a^{\frac12+\frac13-\left(-\frac16\right)}=a^{\frac36+\frac26+\frac16}=a^1=a.$$
**პასუხი:** $a$.
:::
:::

:::example რთული
გამოთვალეთ $\sqrt[3]{2+\sqrt5}+\sqrt[3]{2-\sqrt5}$.
:::solution
აღვნიშნოთ $u=\sqrt[3]{2+\sqrt5}$, $v=\sqrt[3]{2-\sqrt5}$, $t=u+v$. მაშინ
$$u^3+v^3=4,\qquad uv=\sqrt[3]{(2+\sqrt5)(2-\sqrt5)}=\sqrt[3]{-1}=-1.$$
ფორმულით $(u+v)^3=u^3+v^3+3uv(u+v)$:
$$t^3=4-3t\iff t^3+3t-4=0\iff(t-1)(t^2+t+4)=0.$$
$t^2+t+4>0$ (დისკრიმინანტი უარყოფითია), ამიტომ $t=1$.

**პასუხი:** $1$.
:::
:::

## გავრცელებული შეცდომები

- **ლუწი ხარისხის ფესვი უარყოფითიდან.** $\sqrt[4]{-16}$ ნამდვილ რიცხვებში არ არსებობს.
- **მოდულის დავიწყება.** $\sqrt[6]{a^6}=|a|$, და არა $a$.
- **რაციონალური მაჩვენებელი უარყოფითი ფუძით.** $(-8)^{1/3}$ არ არის განმარტებული (ფუძე უნდა იყოს დადებითი), თუმცა $\sqrt[3]{-8}=-2$ არსებობს. თორემ წინააღმდეგობა მიიღება: $(-8)^{2/6}=\sqrt[6]{64}=2$.
- **ფესვების შეკრება.** $\sqrt[3]a+\sqrt[3]b\neq\sqrt[3]{a+b}$.

## შეამოწმე თავი

:::check
გამოთვალეთ $\sqrt[3]{-125}$.
:::answer
$-5$, რადგან $(-5)^3=-125$.
:::
:::

:::check
გამოთვალეთ $32^{0{,}4}$.
:::answer
$32^{2/5}=\left(\sqrt[5]{32}\right)^2=2^2=4$.
:::
:::

:::check
რომელია მეტი: $\sqrt[3]3$ თუ $\sqrt2$?
:::answer
ავიყვანოთ მე-6 ხარისხში: $(\sqrt[3]3)^6=9$, $(\sqrt2)^6=8$. მეტია $\sqrt[3]3$.
:::
:::
