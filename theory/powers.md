## მთავარი იდეა

ხარისხი ერთნაირი მამრავლების ნამრავლის მოკლე ჩანაწერია. ხარისხის ყველა თვისება ერთი იდეიდან გამოდის: დავთვალოთ, რამდენი მამრავლია. ნულოვანი და უარყოფითი მაჩვენებლები ისეა განმარტებული, რომ ეს თვისებები არ დაირღვეს.

ხარისხით იწერება ძალიან დიდი და ძალიან პატარა რიცხვები (სტანდარტული სახე), ხოლო ამოცანებში ხშირად საჭიროა ორი ხარისხის შედარება ან დიდი ხარისხის ბოლო ციფრის პოვნა — გამოთვლის გარეშე.

## განმარტებები და ფორმულები

:::definition
ნატურალური $n$-ისთვის
$$a^n=\underbrace{a\cdot a\cdots a}_{n},\qquad a^1=a.$$
$a$ — ხარისხის **ფუძე**, $n$ — **მაჩვენებელი**.
:::

:::definition
$a\neq0$-ისთვის $a^0=1$ და $a^{-n}=\dfrac{1}{a^n}$. გამოსახულება $0^0$ და $0$-ის უარყოფითი ხარისხი განსაზღვრული არ არის.
:::

:::theorem ხარისხის თვისებები
მთელი $m,n$-ისთვის (ფუძეები არანულოვანია):
$$a^m a^n=a^{m+n},\qquad \frac{a^m}{a^n}=a^{m-n},\qquad (a^m)^n=a^{mn},$$
$$(ab)^n=a^nb^n,\qquad \left(\frac ab\right)^n=\frac{a^n}{b^n}.$$
:::

:::formula ნიშანი
$(-a)^{2k}=a^{2k}$, $(-a)^{2k+1}=-a^{2k+1}$. ლუწი ხარისხი არასოდეს არის უარყოფითი.
:::

:::theorem ხარისხების შედარება
- თუ $a>1$, მაშინ $m>n\Rightarrow a^m>a^n$ (მეტი მაჩვენებელი — მეტი ხარისხი).
- თუ $0<a<1$, მაშინ $m>n\Rightarrow a^m<a^n$ (მაგალითად, $0{,}5^3<0{,}5^2$).
- თუ $0<a<b$ და $n$ ნატურალურია, მაშინ $a^n<b^n$.

ორი ხარისხის შესადარებლად ცდილობენ, ისინი **ერთი ფუძით** ან **ერთი მაჩვენებლით** ჩაწერონ.
:::

:::definition
რიცხვის **სტანდარტული სახე**: $a\cdot10^n$, სადაც $1\le a<10$ და $n$ მთელია. მაგალითად, $0{,}00032=3{,}2\cdot10^{-4}$.
:::

## დამტკიცება

**ნატურალური მაჩვენებლებისთვის.** $a^m a^n$-ში ჯერ $m$ ცალი $a$-ა, მერე კიდევ $n$ ცალი — სულ $m+n$. $(a^m)^n$ არის $n$ ჯგუფი, თითოეულში $m$ ცალი $a$ — სულ $mn$.

**რატომ $a^0=1$ და $a^{-n}=\frac1{a^n}$.** გვინდა, რომ $\frac{a^m}{a^n}=a^{m-n}$ ყოველთვის სრულდებოდეს. როცა $m=n$, მარცხნივ არის $1$, მარჯვნივ $a^0$ — ამიტომ $a^0=1$ ერთადერთი შესაძლო განმარტებაა. როცა $m=0$, მივიღებთ $\frac{1}{a^n}=a^{-n}$. ამის შემდეგ ყველა თვისება მთელი მაჩვენებლებისთვისაც მოწმდება. $\blacksquare$

## ამოხსნილი მაგალითები

:::example მარტივი
გამოთვალეთ $\dfrac{2^5\cdot2^{-3}}{2^{-1}}$.
:::solution
$2^{5+(-3)-(-1)}=2^{3}=8$.

**პასუხი:** $8$.
:::
:::

:::example საშუალო
რომელია მეტი: $2^{300}$ თუ $3^{200}$?
:::solution
ორივე ჩავწეროთ ერთი და იგივე მაჩვენებლით:
$$2^{300}=(2^3)^{100}=8^{100},\qquad 3^{200}=(3^2)^{100}=9^{100}.$$
$8<9$, ამიტომ $8^{100}<9^{100}$.

ხერხი: მაჩვენებლებს ($300$ და $200$) აქვთ საერთო გამყოფი $100$. ამიტომ ორივე ხარისხი შეიძლება ჩავწეროთ როგორც „რაღაც$^{100}$“ და შევადაროთ მხოლოდ ფუძეები.

**პასუხი:** $3^{200}$ მეტია.
:::
:::

:::example რთული
იპოვეთ $7^{2026}$-ის ბოლო ციფრი.
:::solution
ბოლო ციფრი დამოკიდებულია მხოლოდ წინა ხარისხის ბოლო ციფრზე. დავწეროთ რამდენიმე:
$$7^1\to7,\quad7^2\to9,\quad7^3\to3,\quad7^4\to1,\quad7^5\to7,\ \ldots$$
ბოლო ციფრები მეორდება პერიოდით $4$: როგორც კი ბოლო ციფრი $1$ გახდა, შემდეგი ციფრები თავიდან იწყება, რადგან $7^{k+4}=7^k\cdot7^4$ და $7^4$ მთავრდება $1$-ით. $2026=4\cdot506+2$, ამიტომ $7^{2026}$-ის ბოლო ციფრი იგივეა, რაც $7^2$-ისა.

**პასუხი:** $9$.
:::
:::

## გავრცელებული შეცდომები

- **$-2^4$ და $(-2)^4$.** $-2^4=-16$, $(-2)^4=16$. ფრჩხილების გარეშე ხარისხი მხოლოდ ფუძეზე მოქმედებს.
- **ხარისხების შეკრება.** $a^m+a^n\neq a^{m+n}$. მაგალითად, $2^3+2^3=2^4$, და არა $2^6$.
- **ჯამის ხარისხი.** $(a+b)^2\neq a^2+b^2$ — იხ. შემოკლებული გამრავლების ფორმულები.
- **„უარყოფითი მაჩვენებელი — უარყოფითი რიცხვი“.** $2^{-3}=\frac18>0$.

## შეამოწმე თავი

:::check
რისი ტოლია $(-1)^{2025}$?
:::answer
$2025$ კენტია, ამიტომ $(-1)^{2025}=-1$.
:::
:::

:::check
ჩაწერეთ $0{,}00032$ სტანდარტული სახით.
:::answer
$3{,}2\cdot10^{-4}$.
:::
:::

:::check
იპოვეთ $n$, თუ $4^n+4^n+4^n+4^n=2^{2026}$.
:::answer
$4\cdot4^n=4^{n+1}=2^{2n+2}$, ამიტომ $2n+2=2026$, $n=1012$.
:::
:::
