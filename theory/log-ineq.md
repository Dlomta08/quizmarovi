## მთავარი იდეა

ლოგარითმული უტოლობა ორ საფრთხეს აერთიანებს: მაჩვენებლიანი უტოლობის საფრთხეს — ნიშანი ბრუნდება, როცა ფუძე ერთზე ნაკლებია — და ლოგარითმული განტოლების საფრთხეს — დმა. ამიტომ ამოხსნის ყოველი ნაბიჯი ასე იწერება: უტოლობა არგუმენტებს შორის **და** არგუმენტების დადებითობა, ერთ სისტემაში.

## განმარტებები და ფორმულები

:::theorem ძირითადი ტოლფასობები
$$a>1:\quad\log_af(x)>\log_ag(x)\iff\begin{cases}f(x)>g(x),\\ g(x)>0;\end{cases}$$
$$0<a<1:\quad\log_af(x)>\log_ag(x)\iff\begin{cases}f(x)<g(x),\\ f(x)>0.\end{cases}$$
პირობა ყოველთვის ედება **პატარა** არგუმენტს — მეორე მისგან დადებითობას ავტომატურად იღებს.
:::

:::formula რიცხვთან შედარება
$$\log_af(x)>b\iff\log_af(x)>\log_aa^b,$$
და შემდეგ ძირითადი ტოლფასობა. მაგალითად, $a>1$-ზე $\log_af>b\iff f>a^b$.
:::

:::formula ცვლადი ფუძე
$\log_{h(x)}f>\log_{h(x)}g$-ში განიხილება ორი შემთხვევა: $h>1$ და $0<h<1$. ან გამოიყენება რაციონალიზაცია: დმა-ზე $\log_hf-\log_hg$-ის ნიშანი ემთხვევა $(h-1)(f-g)$-ის ნიშანს.
:::

## დამტკიცება

$a>1$: $y=\log_at$ ზრდადია $(0;+\infty)$-ზე. თუ ორივე ლოგარითმი განსაზღვრულია ($f,g>0$), მაშინ $\log_af>\log_ag\iff f>g$. ხოლო პირობები „$f>g$ და $g>0$“ ერთად ნიშნავს $f>g>0$-ს — ორივე დადებითია.

$0<a<1$: ფუნქცია კლებადია, უტოლობა ბრუნდება: $f<g$; პატარა არგუმენტი ახლა $f$-ია, ამიტომ პირობაა $f>0$. $\blacksquare$

## ამოხსნილი მაგალითები

:::example მარტივი
ამოხსენით $\log_2(x-1)<3$.
:::solution
$0<x-1<2^3$, ანუ $1<x<9$.

**პასუხი:** $x\in(1;\,9)$.
:::
:::

:::example საშუალო
ამოხსენით $\log_{\frac13}(2x+1)\ge\log_{\frac13}(x+4)$.
:::solution
ფუძე $<1$ — ნიშანი ბრუნდება; პატარა არგუმენტი $2x+1$ დადებითი უნდა იყოს:
$$\begin{cases}2x+1\le x+4,\\ 2x+1>0\end{cases}\iff-\frac12<x\le3.$$
**პასუხი:** $x\in\left(-\dfrac12;\,3\right]$.
:::
:::

:::example რთული
ამოხსენით $\log_2^2x-\log_2x-2\le0$.
:::solution
დმა: $x>0$. $t=\log_2x$: $t^2-t-2\le0\iff-1\le t\le2$. ანუ $-1\le\log_2x\le2\iff\frac12\le x\le4$.

**პასუხი:** $x\in\left[\dfrac12;\,4\right]$.
:::
:::

## გავრცელებული შეცდომები

- **დმა-ს გამოტოვება.** $\log_2(x-1)<3$-დან მხოლოდ $x<9$ არასწორია: საჭიროა $x>1$-იც.
- **ნიშნის შეუბრუნებლობა $0<a<1$-ზე.**
- **არასწორი არგუმენტის შეზღუდვა.** პირობა „$>0$“ ედება იმ არგუმენტს, რომელიც უტოლობით უფრო **პატარაა**.
- **ცვლადი ფუძე ერთი შემთხვევით.** $\log_x2>1$-ში $x>1$ და $0<x<1$ ცალ-ცალკე განიხილება.

## შეამოწმე თავი

:::check
ამოხსენით $\lg x>1$.
:::answer
$x>10$.
:::
:::

:::check
ამოხსენით $\log_{0{,}5}x>-1$.
:::answer
ფუძე $<1$: $0<x<0{,}5^{-1}=2$.
:::
:::

:::check
ამოხსენით $\log_3(x+2)\le0$.
:::answer
$0<x+2\le1$, ანუ $-2<x\le-1$.
:::
:::
