## მთავარი იდეა

ფარდობა გვიჩვენებს, რამდენჯერ არის ერთი სიდიდე მეორეზე მეტი. პროპორცია ორი ფარდობის ტოლობაა. ის ყველგან გვხვდება: რუკის მასშტაბში, რეცეპტებში, მსგავს ფიგურებში, ფიზიკის ფორმულებში. ორ სიდიდეს შორის კავშირი ხშირად ორიდან ერთ-ერთია: ერთის გაზრდა მეორეს იმდენჯერვე ზრდის (პირდაპირპროპორციულობა) ან იმდენჯერვე ამცირებს (უკუპროპორციულობა).

## განმარტებები და ფორმულები

:::definition
$a$ და $b$ რიცხვების **ფარდობა** ($b\neq0$) არის განაყოფი $a:b=\dfrac ab$. **პროპორცია** არის ორი ფარდობის ტოლობა:
$$\frac ab=\frac cd\qquad(b,d\neq0).$$
$a$ და $d$ — კიდურა წევრები, $b$ და $c$ — შუა წევრები.
:::

:::theorem პროპორციის ძირითადი თვისება
$\dfrac ab=\dfrac cd\iff ad=bc$: კიდურა წევრების ნამრავლი შუა წევრების ნამრავლის ტოლია.
:::

:::formula გამოყვანილი პროპორციები
თუ $\dfrac ab=\dfrac cd$, მაშინ (როცა მნიშვნელები არ არის ნული)
$$\frac ac=\frac bd,\qquad \frac{a+b}{b}=\frac{c+d}{d},\qquad \frac{a-b}{b}=\frac{c-d}{d},\qquad \frac{a+c}{b+d}=\frac ab.$$
:::

:::definition
$y$ **პირდაპირპროპორციულია** $x$-ისა, თუ $y=kx$ რაიმე მუდმივი $k\neq0$-ისთვის. $y$ **უკუპროპორციულია** $x$-ისა, თუ $y=\dfrac kx$, ანუ $xy=k$.
:::

:::formula მოცემული ფარდობით დაყოფა
$S$ რიცხვის $a:b:c$ ფარდობით დასაყოფად ვწერთ ნაწილებს როგორც $ak,\ bk,\ ck$. მაშინ $k=\dfrac{S}{a+b+c}$.
:::

## დამტკიცება

**ძირითადი თვისება.** $\dfrac ab=\dfrac cd$ ტოლობის ორივე მხარე გავამრავლოთ $bd\neq0$-ზე: მივიღებთ $ad=bc$. პირიქით, $ad=bc$ გავყოთ $bd$-ზე.

**ერთ-ერთი გამოყვანილი პროპორცია.** ორივე მხარეს დავუმატოთ $1$:
$$\frac ab+1=\frac cd+1\iff\frac{a+b}{b}=\frac{c+d}{d}.$$

**ტოლი ფარდობების ჯამი.** ვთქვათ $\dfrac ab=\dfrac cd=k$, ანუ $a=kb$, $c=kd$. მაშინ $a+c=k(b+d)$ და, თუ $b+d\neq0$, $\dfrac{a+c}{b+d}=k$. $\blacksquare$

## ამოხსნილი მაგალითები

:::example მარტივი
ამოხსენით პროპორცია $\dfrac{x}{12}=\dfrac58$.
:::solution
ძირითადი თვისებით $8x=5\cdot12=60$, $x=7{,}5$.

**პასუხი:** $x=7{,}5$.
:::
:::

:::example საშუალო
$5$ მუშა სამუშაოს $12$ დღეში ასრულებს. რამდენ დღეში შეასრულებს იმავე სამუშაოს $6$ მუშა (ყველა ერთნაირად მუშაობს)?
:::solution
მუშების რაოდენობა და დღეები უკუპროპორციულია: მათი ნამრავლი (სამუშაოს მოცულობა „კაც-დღეებში“) მუდმივია.

$5\cdot12=60$ კაც-დღე, ამიტომ $6$ მუშას დასჭირდება $60:6=10$ დღე.

**პასუხი:** $10$ დღე.
:::
:::

:::example რთული
$a:b=2:3$, $b:c=4:5$ და $a+b+c=70$. იპოვეთ $a$, $b$, $c$.
:::solution
ფარდობები ისე ჩავწეროთ, რომ $b$-ს ერთი და იგივე რიცხვი შეესაბამებოდეს. $3$-ისა და $4$-ის უსჯ არის $12$:
$$a:b=2:3=8:12,\qquad b:c=4:5=12:15.$$
ამიტომ $a:b:c=8:12:15$. ვთქვათ $a=8k$, $b=12k$, $c=15k$. მაშინ $35k=70$, $k=2$.

**პასუხი:** $a=16$, $b=24$, $c=30$.
:::
:::

## გავრცელებული შეცდომები

- **უკუპროპორციულობა პირდაპირის ნაცვლად.** მეტი მუშა ნაკლებ დღეს ნიშნავს. სანამ ფორმულას დაწერთ, ჰკითხეთ თავს: ერთის გაზრდისას მეორე იზრდება თუ მცირდება?
- **„იზრდება“ ≠ „პროპორციულია“.** $y=x+3$ ზრდადია, მაგრამ პროპორციული არ არის: $x$-ის გაორმაგება $y$-ს არ აორმაგებს.
- **ნაწილი და მთელი.** $2:3$ ფარდობით დაყოფისას პირველი ნაწილი მთელის $\frac25$-ია და არა $\frac23$.
- **სხვადასხვა ერთეულები.** ფარდობის შედგენამდე სიდიდეები ერთსა და იმავე ერთეულში უნდა გადავიყვანოთ (მაგალითად, სმ და მ).

## შეამოწმე თავი

:::check
ამოხსენით $3:x=4:10$.
:::answer
$4x=30$, $x=7{,}5$.
:::
:::

:::check
$y$ პირდაპირპროპორციულია $x$-ისა და $x=4$-ისთვის $y=12$. იპოვეთ $y$, როცა $x=7$.
:::answer
$k=12:4=3$, ამიტომ $y=3\cdot7=21$.
:::
:::

:::check
მუდმივ მანძილზე როგორ არის დაკავშირებული სიჩქარე და დრო?
:::answer
უკუპროპორციულად: $v\cdot t=s$ მუდმივია.
:::
:::
