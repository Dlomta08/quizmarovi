## მთავარი იდეა

წარმოებულები და ზღვრები ერთად ფუნქციის სრულ „პორტრეტს“ იძლევა: სად არის განსაზღვრული, სად კვეთს ღერძებს, საით მიდის, სად აქვს მწვერვალები და როგორ იღუნება. ამ ინფორმაციიდან გრაფიკი თითქმის თავისით იხაზება.

გრაფიკი ხშირად არა მიზანი, არამედ ინსტრუმენტია: მისით ვთვლით განტოლების ფესვების რაოდენობას, ვპოულობთ მნიშვნელობათა სიმრავლეს და ვამტკიცებთ უტოლობებს.

## განმარტებები და ფორმულები

:::formula გამოკვლევის გეგმა
1. განსაზღვრის არე; წყვეტის წერტილები.
2. ლუწ-კენტობა, პერიოდულობა (თუ არის — კვლევა მცირდება).
3. ღერძებთან გადაკვეთა; ნიშნის შუალედები.
4. ასიმპტოტები (ვერტიკალური, ჰორიზონტალური, დახრილი).
5. $f'$: მონოტონურობა და ექსტრემუმები.
6. $f''$: ამოზნექილობა და გადაღუნვა.
7. ცხრილი და გრაფიკი.
:::

:::note ფესვების რაოდენობა
$f(x)=a$ განტოლების ამონახსნების რაოდენობა არის $y=f(x)$ გრაფიკისა და $y=a$ ჰორიზონტალური წრფის გადაკვეთის წერტილების რაოდენობა. ამიტომ საკმარისია ვიცოდეთ ექსტრემუმები და ზღვრები.
:::

:::note
თუ $f$ მკაცრად მონოტონურია შუალედზე, მას იქ $f(x)=a$-ს მაქსიმუმ ერთი ამონახსნი აქვს.
:::

## ამოხსნილი მაგალითები

:::example მარტივი
გამოიკვლიეთ $f(x)=x^3-3x^2$.
:::solution
არე $\mathbb R$; ნულები $x=0$ (ორმაგი), $x=3$. $f'=3x(x-2)$: მაქსიმუმი $f(0)=0$, მინიმუმი $f(2)=-4$. $f''=6x-6$: გადაღუნვა $(1,-2)$. $x\to\pm\infty$-ზე $f\to\pm\infty$.

გრაფიკი: $-\infty$-დან ამოდის $(0,0)$-მდე, ეშვება $(2,-4)$-მდე, შემდეგ ამოდის და $x=3$-ში ღერძს კვეთს.
:::
:::

:::example საშუალო
გამოიკვლიეთ $f(x)=\dfrac{x}{x^2+1}$ და იპოვეთ მნიშვნელობათა სიმრავლე.
:::solution
არე $\mathbb R$, კენტია. $x\to\pm\infty$: $f\to0$ — ასიმპტოტი $y=0$.
$$f'(x)=\frac{(x^2+1)-2x^2}{(x^2+1)^2}=\frac{1-x^2}{(x^2+1)^2}.$$
$x=-1$ — მინიმუმი $-\dfrac12$, $x=1$ — მაქსიმუმი $\dfrac12$.

**პასუხი:** $E(f)=\left[-\dfrac12,\dfrac12\right]$.
:::
:::

:::example რთული
$a$-ს რა მნიშვნელობებისთვის რამდენი ამონახსნი აქვს $x^3-3x=a$ განტოლებას?
:::solution
$f(x)=x^3-3x$: მაქსიმუმი $f(-1)=2$, მინიმუმი $f(1)=-2$, $x\to\pm\infty$-ზე $f\to\pm\infty$.

ჰორიზონტალური წრფე $y=a$ გრაფიკს კვეთს:
- $|a|>2$ — ერთხელ;
- $a=\pm2$ — ორჯერ (ერთი შეხების წერტილი ექსტრემუმში);
- $|a|<2$ — სამჯერ.

**პასუხი:** $|a|<2$: $3$; $|a|=2$: $2$; $|a|>2$: $1$.
:::
:::

## გავრცელებული შეცდომები

- **ასიმპტოტების გამოტოვება.** გრაფიკის ფორმა შორს ხშირად სწორედ ასიმპტოტით განისაზღვრება.
- **ექსტრემუმი = უდიდესი მნიშვნელობა.** ლოკალური მაქსიმუმი შეიძლება არ იყოს უდიდესი მნიშვნელობა — მაგ. $x^3-3x$-ს უდიდესი მნიშვნელობა საერთოდ არ აქვს.
- **არის გარეთ კვლევა.** კრიტიკული წერტილი, რომელიც განსაზღვრის არეში არ შედის, ექსტრემუმი არ არის.

## შეამოწმე თავი

:::check
იპოვეთ $xe^{-x}$-ის მნიშვნელობათა სიმრავლე $[0,\infty)$-ზე.
:::answer
$f'=(1-x)e^{-x}$, მაქსიმუმი $f(1)=\dfrac1e$; $f(0)=0$, $f\to0$. პასუხი: $\left[0,\dfrac1e\right]$.
:::
:::

:::check
რამდენი ამონახსნი აქვს $x^3+x=a$-ს ნებისმიერი $a$-სთვის?
:::answer
ზუსტად ერთი: $f'=3x^2+1>0$, ფუნქცია ზრდადია და ყველა მნიშვნელობას იღებს.
:::
:::

:::check
იპოვეთ $\dfrac{x^2}{x-1}$-ის ექსტრემუმები.
:::answer
$f'=\dfrac{x(x-2)}{(x-1)^2}$: მაქსიმუმი $f(0)=0$, მინიმუმი $f(2)=4$.
:::
:::
