## მთავარი იდეა

$2^{3}$, $2^{-1}$ და $2^{1/2}$ უკვე განმარტებულია. რას ნიშნავს $2^{\sqrt2}$? $\sqrt2$-ს უახლოვდება რაციონალური რიცხვები $1{,}4$; $1{,}41$; $1{,}414$; ..., და ხარისხები $2^{1{,}4}$, $2^{1{,}41}$, $2^{1{,}414}$, ... ერთ რიცხვს უახლოვდება — ეს არის $2^{\sqrt2}$. ასე ხარისხი ყველა ნამდვილი მაჩვენებლისთვის განიმარტება და ჩნდება **მაჩვენებლიანი ფუნქცია** $y=a^x$.

## განმარტებები და ფორმულები

:::definition
$a>0$ და ირაციონალური $x$-ისთვის $a^x$ არის რიცხვი, რომელსაც უახლოვდება $a^{r}$, როცა რაციონალური $r$ უახლოვდება $x$-ს. ასე განმარტებული ხარისხისთვის რჩება ყველა წესი:
$$a^xa^y=a^{x+y},\qquad \frac{a^x}{a^y}=a^{x-y},\qquad (a^x)^y=a^{xy},\qquad (ab)^x=a^xb^x.$$
:::

:::definition
**მაჩვენებლიანი ფუნქცია**: $y=a^x$, სადაც $a>0$, $a\neq1$.
:::

:::theorem მაჩვენებლიანი ფუნქციის თვისებები
- $D=\mathbb R$, $E=(0;+\infty)$: $a^x>0$ ყოველთვის.
- $a^0=1$ — გრაფიკი გადის $(0;1)$-ზე.
- $a>1$: ზრდადია; $0<a<1$: კლებადია.
- $a>1$-ზე: $x\to+\infty$ ⇒ $a^x\to+\infty$, $x\to-\infty$ ⇒ $a^x\to0$ ($Ox$ ღერძი ჰორიზონტალური ასიმპტოტაა).
:::

:::formula შედარება
$a>1$: $a^x>a^y\iff x>y$. $0<a<1$: $a^x>a^y\iff x<y$.
:::

## დამტკიცება

**ზრდადობა ($a>1$) რაციონალური მაჩვენებლებისთვის.** ჯერ: თუ $r>0$ რაციონალურია, მაშინ $a^r>1$. მართლაც, $r=\frac mn$ და $a^m>1$ (ერთზე მეტის ნატურალური ხარისხი), ამიტომ $\sqrt[n]{a^m}>1$.

ახლა $x<y$ (რაციონალურები): $a^y=a^x\cdot a^{y-x}$, სადაც $a^x>0$ და $a^{y-x}>1$. ამიტომ $a^y>a^x$. ირაციონალურ მაჩვენებლებზე თვისება ზღვარზე გადასვლით ვრცელდება. $\blacksquare$

## ამოხსნილი მაგალითები

:::example მარტივი
გაამარტივეთ $\dfrac{3^{\sqrt2+1}\cdot3^{1-\sqrt2}}{9^{0{,}5}}$.
:::solution
$\frac{3^{2}}{3^1}=3$.

**პასუხი:** $3$.
:::
:::

:::example საშუალო
შეადარეთ $\left(\dfrac23\right)^{\sqrt3}$ და $\left(\dfrac23\right)^{1{,}7}$.
:::solution
ფუძე $\frac23<1$ — ფუნქცია კლებადია. $\sqrt3\approx1{,}732>1{,}7$, ამიტომ $\left(\frac23\right)^{\sqrt3}<\left(\frac23\right)^{1{,}7}$.
:::
:::

:::example რთული
იპოვეთ $y=2^x+2^{-x}$-ის მნიშვნელობათა სიმრავლე.
:::solution
$2^x>0$, ამიტომ საშუალოების უტოლობით $2^x+\frac1{2^x}\ge2$, ტოლობით $x=0$-ზე.

ყველა $y\ge2$ მიიღწევა: $t+\frac1t=y$-ს ($t=2^x>0$) აქვს დადებითი ამონახსნი $t=\frac{y+\sqrt{y^2-4}}2$, და შემდეგ $x=\log_2t$.

**პასუხი:** $[2;\,+\infty)$.
:::
:::

## გავრცელებული შეცდომები

- **უარყოფითი ფუძე.** $(-2)^{\sqrt2}$ განსაზღვრული არ არის; მაჩვენებლიან ფუნქციაში $a>0$.
- **$a^x$ შეიძლება იყოს უარყოფითი?** არა: $a^x>0$ ყოველთვის. ამიტომ $2^x=-1$ ამონახსნი არ აქვს.
- **კლებადობის დავიწყება $0<a<1$-ზე.** შედარებისას ნიშანი ბრუნდება.
- **$a^x\cdot b^x=(ab)^{2x}$.** სწორია $(ab)^x$.

## შეამოწმე თავი

:::check
რისი ტოლია $5^0$ და $5^{-2}$?
:::answer
$1$ და $\frac1{25}$.
:::
:::

:::check
ზრდადია თუ კლებადი $y=\left(\dfrac{\pi}{3}\right)^x$?
:::answer
ზრდადი: $\frac\pi3>1$.
:::
:::

:::check
იპოვეთ $y=3^x-1$-ის მნიშვნელობათა სიმრავლე.
:::answer
$3^x\in(0;+\infty)$, ამიტომ $y\in(-1;+\infty)$.
:::
:::
