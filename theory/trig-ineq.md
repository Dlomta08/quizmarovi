## მთავარი იდეა

ტრიგონომეტრიული უტოლობის ამონახსნი შუალედების სერიაა: ერთი ბრუნის შიგნით ვპოულობთ შუალედს და შემდეგ ვამატებთ პერიოდს. უმარტივესი უტოლობები ერთეულოვანი წრეწირით იხსნება: $\sin x>a$ ნიშნავს, რომ $P_x$ წერტილი $y=a$ წრფის ზემოთაა. რთული უტოლობები ჩანაცვლებით ან გარდაქმნით უმარტივესზე დადის.

## განმარტებები და ფორმულები

:::formula ერთეულოვანი წრეწირის მეთოდი
1. ავაგოთ წრფე $y=a$ (სინუსისთვის) ან $x=a$ (კოსინუსისთვის).
2. ვიპოვოთ წრეწირთან გადაკვეთის წერტილები — ისინი შეესაბამება $\arcsin a$, $\pi-\arcsin a$ (ან $\pm\arccos a$) კუთხეებს.
3. მოვნიშნოთ რკალი, სადაც უტოლობა სრულდება, და ჩავწეროთ ის შუალედად, რომლის მარცხენა ბოლო **ნაკლებია** მარჯვენაზე (საათის ისრის საწინააღმდეგოდ მოძრაობით).
4. დავამატოთ პერიოდი: $+2\pi k$ (სინუსი, კოსინუსი) ან $+\pi k$ (ტანგენსი).
:::

:::formula უმარტივესი უტოლობები ($|a|<1$, $k\in\mathbb Z$)
$$\sin x>a\iff \arcsin a+2\pi k<x<\pi-\arcsin a+2\pi k,$$
$$\cos x>a\iff -\arccos a+2\pi k<x<\arccos a+2\pi k,$$
$$\operatorname{tg}x>a\iff \operatorname{arctg}a+\pi k<x<\frac\pi2+\pi k.$$
:::

:::note
თუ $a\ge1$, $\sin x>a$ ამონახსნი არ აქვს; თუ $a<-1$, მისი ამონახსნია ყოველი $x$.
:::

## დამტკიცება

**$\sin x>a$.** $\sin x$ არის $P_x$-ის ორდინატა. $|a|<1$-ისას წრფე $y=a$ წრეწირს კვეთს ორ წერტილში, რომლებიც შეესაბამება $x_1=\arcsin a\in\left(-\frac\pi2;\frac\pi2\right)$ და $x_2=\pi-\arcsin a$ კუთხეებს. $x_1$-დან $x_2$-მდე საათის ისრის საწინააღმდეგოდ მოძრაობისას წერტილი გადის წრეწირის ზედა რკალზე — იქ $y>a$. დანარჩენ რკალზე $y<a$. პერიოდულობით ვამატებთ $2\pi k$-ს. $\blacksquare$

## ამოხსნილი მაგალითები

:::example მარტივი
ამოხსენით $\cos x\ge\dfrac12$.
:::solution
$\arccos\frac12=\frac\pi3$. წრეწირზე $x\ge\frac12$ — მარჯვენა რკალი $-\frac\pi3$-დან $\frac\pi3$-მდე.

**პასუხი:** $-\dfrac\pi3+2\pi k\le x\le\dfrac\pi3+2\pi k$, $k\in\mathbb Z$.
:::
:::

:::example საშუალო
ამოხსენით $\sin x<-\dfrac{\sqrt2}2$.
:::solution
$y=-\frac{\sqrt2}2$ წრეწირს კვეთს $-\frac\pi4$ და $-\frac{3\pi}4$ (ანუ $\frac{5\pi}4$) კუთხეებზე. $y<-\frac{\sqrt2}2$ — ქვედა რკალი $\frac{5\pi}4$-დან $\frac{7\pi}4$-მდე (მარცხენა ბოლო ნაკლებია მარჯვენაზე).

**პასუხი:** $\dfrac{5\pi}4+2\pi k<x<\dfrac{7\pi}4+2\pi k$, $k\in\mathbb Z$.
:::
:::

:::example რთული
ამოხსენით $2\sin^2x+\sin x-1>0$.
:::solution
$t=\sin x$: $2t^2+t-1>0\iff(2t-1)(t+1)>0\iff t<-1$ ან $t>\frac12$.

$\sin x<-1$ შეუძლებელია. $\sin x>\frac12$: $\frac\pi6+2\pi k<x<\frac{5\pi}6+2\pi k$.

**პასუხი:** $\dfrac\pi6+2\pi k<x<\dfrac{5\pi}6+2\pi k$, $k\in\mathbb Z$.
:::
:::

## გავრცელებული შეცდომები

- **შუალედი „უკუღმა“.** $\sin x<-\frac{\sqrt2}2$-ისთვის $-\frac\pi4<x<-\frac{3\pi}4$ უაზროა: მარცხენა ბოლო მეტია მარჯვენაზე. სწორია $\frac{5\pi}4<x<\frac{7\pi}4$ (ან $-\frac{3\pi}4<x<-\frac\pi4$).
- **პერიოდის დავიწყება.** პასუხი სერიაა, არა ერთი შუალედი.
- **ტანგენსის „გაჭედვა“.** $\operatorname{tg}x>a$-ის შუალედის მარჯვენა ბოლოა $\frac\pi2+\pi k$, სადაც ტანგენსი განსაზღვრული არ არის — ის არასოდეს შედის.
- **$|t|\le1$-ის დავიწყება ჩანაცვლებისას.**

## შეამოწმე თავი

:::check
ამოხსენით $\sin x\ge1$.
:::answer
მხოლოდ ტოლობა: $x=\frac\pi2+2\pi k$.
:::
:::

:::check
ამოხსენით $\operatorname{tg}x<1$.
:::answer
$-\frac\pi2+\pi k<x<\frac\pi4+\pi k$.
:::
:::

:::check
ამოხსენით $\cos x<2$.
:::answer
ყოველი $x$.
:::
:::
