## მთავარი იდეა

მაჩვენებლიანი უტოლობა მაჩვენებლების უტოლობად იქცევა — მაგრამ ფუძის მიხედვით. თუ ფუძე ერთზე მეტია, ფუნქცია ზრდადია და ნიშანი რჩება. თუ ფუძე ერთზე ნაკლებია, ფუნქცია კლებადია და ნიშანი ბრუნდება. დანარჩენი ხერხები განტოლებების მსგავსია: ერთი ფუძე, ჩანაცვლება $t=a^x>0$.

## განმარტებები და ფორმულები

:::theorem ძირითადი ტოლფასობები
$$a>1:\quad a^{f(x)}>a^{g(x)}\iff f(x)>g(x);$$
$$0<a<1:\quad a^{f(x)}>a^{g(x)}\iff f(x)<g(x).$$
:::

:::formula ხერხები
1. ორივე მხარე ჩავწეროთ ერთი ფუძით და გამოვიყენოთ ძირითადი ტოლფასობა.
2. ჩანაცვლება $t=a^x>0$: ამოვხსნათ $t$-ის უტოლობა, **გადავკვეთოთ ის $t>0$-თან** და დავბრუნდეთ $x$-ზე.
3. თუ ერთ მხარეს ფიქსირებული რიცხვია, რომელიც ფუძის ხარისხი არ არის: $2^x>5\iff x>\log_25$.
:::

:::formula სწრაფი შემოწმებები
- $a^x>0$ — ყოველთვის; ამიტომ $a^x>-3$-ის ამონახსნია ყველა $x$, ხოლო $a^x<0$-ს ამონახსნი არ აქვს.
- $a^{f(x)}>1\iff f(x)>0$, თუ $a>1$.
:::

## დამტკიცება

$a>1$-ზე $y=a^t$ ზრდადია: $t_1>t_2\Rightarrow a^{t_1}>a^{t_2}$. პირიქითაც: თუ $a^{t_1}>a^{t_2}$, მაგრამ $t_1\le t_2$, მაშინ ზრდადობით $a^{t_1}\le a^{t_2}$ — წინააღმდეგობა. ამიტომ $a^{f}>a^{g}\iff f>g$.

$0<a<1$-ზე ფუნქცია კლებადია, და იგივე მსჯელობა ნიშანს აბრუნებს. $\blacksquare$

## ამოხსნილი მაგალითები

:::example მარტივი
ამოხსენით $2^{3x-1}>16$.
:::solution
$2^{3x-1}>2^4$, ფუძე $2>1$: $3x-1>4$, $x>\frac53$.

**პასუხი:** $x\in\left(\dfrac53;\,+\infty\right)$.
:::
:::

:::example საშუალო
ამოხსენით $\left(\dfrac13\right)^{x^2-2x}\ge\dfrac1{27}$.
:::solution
$\left(\frac13\right)^{x^2-2x}\ge\left(\frac13\right)^3$, ფუძე $<1$ — ნიშანი ბრუნდება:
$$x^2-2x\le3\iff x^2-2x-3\le0\iff-1\le x\le3.$$
**პასუხი:** $x\in[-1;\,3]$.
:::
:::

:::example რთული
ამოხსენით $9^x-4\cdot3^x+3<0$.
:::solution
$t=3^x>0$: $t^2-4t+3<0\iff1<t<3$. ეს უკვე $t>0$-ის ნაწილია. $1<3^x<3\iff0<x<1$.

**პასუხი:** $x\in(0;\,1)$.
:::
:::

## გავრცელებული შეცდომები

- **ნიშნის შეუბრუნებლობა $0<a<1$-ზე.** ყველაზე ხშირი შეცდომა: $\left(\frac12\right)^x>\frac14\iff x<2$.
- **$t>0$-ის დავიწყება.** მაგ., $t^2-t-2>0$ იძლევა $t<-1$ ან $t>2$; პირველი შეუძლებელია, რჩება $3^x>2$.
- **ფუძის შეცვლა ნიშნის გარეშე.** $\left(\frac13\right)^{x}=3^{-x}$ — ჩანაწერის შეცვლა ნიშანს არ ცვლის, მაგრამ უცნობის წინ მინუსი ჩნდება.
- **მარჯვენა მხარე არ არის ფუძის ხარისხი.** $2^x>3$-ში პასუხი $x>\log_23$, და არა „$x>1{,}5$“.

## შეამოწმე თავი

:::check
ამოხსენით $\left(\dfrac12\right)^x>\dfrac14$.
:::answer
$x<2$.
:::
:::

:::check
ამოხსენით $5^x>-1$.
:::answer
ყოველი $x$.
:::
:::

:::check
ამოხსენით $3^{x-2}\le1$.
:::answer
$x-2\le0$, $x\le2$.
:::
:::
