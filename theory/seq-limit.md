## მთავარი იდეა

მიმდევრობის ზღვარი არის რიცხვი, რომელსაც მიმდევრობის წევრები **რაგინდ ახლოს** უახლოვდება და ახლოს რჩება. მაგალითად, $\dfrac1n$ წევრები უახლოვდება $0$-ს: საკმარისად დიდი $n$-ისთვის ისინი $0$-დან ნებისმიერ წინასწარ მოცემულ მანძილზე ნაკლებით არის დაშორებული.

ზღვრების გამოთვლა ხშირად მარტივი ხერხებით ხდება: წილადში ვყოფთ უფროს ხარისხზე, ფესვებში ვიყენებთ შეუღლებულს. განსაკუთრებული ზღვარია რიცხვი $e\approx2.718$.

## განმარტებები და ფორმულები

:::definition
$\lim\limits_{n\to\infty}a_n=A$, თუ ნებისმიერი $\varepsilon>0$-ისთვის არსებობს $N$, რომ ყოველი $n>N$-ისთვის $|a_n-A|<\varepsilon$. მიმდევრობა, რომელსაც ზღვარი აქვს, **კრებადია**.
:::

:::theorem ზღვრების თვისებები
თუ $a_n\to A$, $b_n\to B$, მაშინ $a_n\pm b_n\to A\pm B$, $a_nb_n\to AB$, და $\dfrac{a_n}{b_n}\to\dfrac AB$ ($B\ne0$). **ორი პოლიციელის თეორემა:** თუ $a_n\le c_n\le b_n$ და $a_n,b_n\to A$, მაშინ $c_n\to A$.
:::

:::theorem ვაიერშტრასის თეორემა
მონოტონური და შემოსაზღვრული მიმდევრობა კრებადია.
:::

:::formula მნიშვნელოვანი ზღვრები
$$\frac1n\to0,\qquad q^n\to0\ (|q|<1),\qquad \sqrt[n]{n}\to1,\qquad \left(1+\frac1n\right)^n\to e.$$
უსასრულო კლებადი გეომეტრიული პროგრესიის ჯამი: $S=\dfrac{b_1}{1-q}$ ($|q|<1$).
:::

## დამტკიცება

**$\dfrac1n\to0$.** მოცემულია $\varepsilon>0$. ავიღოთ $N>\dfrac1\varepsilon$. მაშინ $n>N$-ისთვის $\left|\dfrac1n-0\right|=\dfrac1n<\dfrac1N<\varepsilon$. $\blacksquare$

**პროგრესიის ჯამი.** $S_n=\dfrac{b_1(1-q^n)}{1-q}$. $q^n\to0$, ამიტომ $S_n\to\dfrac{b_1}{1-q}$.

**$e$.** შეიძლება ვაჩვენოთ, რომ $\left(1+\frac1n\right)^n$ ზრდადია და $3$-ზე ნაკლებია; ვაიერშტრასით მას ზღვარი აქვს — ეს არის $e$.

## ამოხსნილი მაგალითები

:::example მარტივი
იპოვეთ $\lim\limits_{n\to\infty}\dfrac{3n^2+1}{2n^2-n}$.
:::solution
გავყოთ $n^2$-ზე: $\dfrac{3+\frac1{n^2}}{2-\frac1n}\to\dfrac32$.

**პასუხი:** $\dfrac32$.
:::
:::

:::example საშუალო
იპოვეთ $\lim\limits_{n\to\infty}\left(\sqrt{n^2+n}-n\right)$.
:::solution
გავამრავლოთ და გავყოთ შეუღლებულზე:
$$\sqrt{n^2+n}-n=\frac{n}{\sqrt{n^2+n}+n}=\frac{1}{\sqrt{1+\frac1n}+1}\to\frac12.$$

**პასუხი:** $\dfrac12$.
:::
:::

:::example რთული
$a_1=\sqrt2$, $a_{n+1}=\sqrt{2+a_n}$. დაამტკიცეთ, რომ მიმდევრობა კრებადია და იპოვეთ ზღვარი.
:::solution
**შემოსაზღვრულობა:** $a_n<2$ ინდუქციით: $a_1<2$; თუ $a_n<2$, მაშინ $a_{n+1}<\sqrt{4}=2$.

**ზრდადობა:** $a_{n+1}^2-a_n^2=2+a_n-a_n^2=(2-a_n)(1+a_n)>0$.

ვაიერშტრასით არსებობს $L=\lim a_n$. ტოლობაში $a_{n+1}=\sqrt{2+a_n}$ გადავიდეთ ზღვარზე: $L=\sqrt{2+L}$, $L^2-L-2=0$, $L=2$ (დადებითია).

**პასუხი:** $2$.
:::
:::

## გავრცელებული შეცდომები

- **„$\infty-\infty=0$“.** $\sqrt{n^2+n}-n$ არ მიისწრაფვის $0$-სკენ — ასეთი სახის ზღვრები ცალკე ითვლება.
- **„$1^\infty=1$“.** $\left(1+\frac1n\right)^n\to e$, არა $1$.
- **ზღვარზე გადასვლა არსებობის დამტკიცების გარეშე.** $L=\sqrt{2+L}$ ჩაწერამდე უნდა ვიცოდეთ, რომ ზღვარი არსებობს.

## შეამოწმე თავი

:::check
იპოვეთ $\lim\left(1+\dfrac1n\right)^{3n}$.
:::answer
$\left(\left(1+\frac1n\right)^n\right)^3\to e^3$.
:::
:::

:::check
ჩაწერეთ $0.(3)$ უსასრულო პროგრესიის ჯამად და იპოვეთ.
:::answer
$\dfrac{3}{10}+\dfrac{3}{100}+\dots=\dfrac{0.3}{1-0.1}=\dfrac13$.
:::
:::

:::check
იპოვეთ $\lim\dfrac{2^n+3^n}{3^n}$.
:::answer
$\left(\frac23\right)^n+1\to1$.
:::
:::
