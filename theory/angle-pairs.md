## მთავარი იდეა

როცა ორი წრფე იკვეთება, ოთხი კუთხე წარმოიქმნება. მათ შორის მხოლოდ ორი სხვადასხვა ზომაა: მეზობელი კუთხეები ჯამში $180^\circ$-ს იძლევა, ერთმანეთის მოპირდაპირე კუთხეები კი ტოლია. ამიტომ საკმარისია ერთი კუთხის ცოდნა, რომ ოთხივე ვიპოვოთ.

ეს ორი ფაქტი — მოსაზღვრე კუთხეების ჯამი და ვერტიკალური კუთხეების ტოლობა — თითქმის ყველა გეომეტრიულ ამოცანაში გამოიყენება.

## განმარტებები და ფორმულები

:::definition
ორი კუთხე **მოსაზღვრეა**, თუ მათ ერთი გვერდი საერთო აქვთ, ხოლო დანარჩენი ორი გვერდი ერთ წრფეზე მდებარე ურთიერთსაწინააღმდეგო სხივებია.
:::

:::theorem
მოსაზღვრე კუთხეების ჯამი $180^\circ$-ია. ამიტომ მართი კუთხის მოსაზღვრე კუთხე მართია, მახვილისა — ბლაგვი, ბლაგვისა — მახვილი.
:::

:::definition
ორი კუთხე **ვერტიკალურია**, თუ ერთი კუთხის გვერდები მეორის გვერდების გაგრძელებაა.
:::

:::theorem
ვერტიკალური კუთხეები ტოლია.
:::

:::definition
ორი წრფე **მართობულია** ($a\perp b$), თუ ისინი მართი კუთხით იკვეთება. მაშინ ოთხივე კუთხე მართია. წრფის ყოველ წერტილზე გადის ამ წრფის მართობული ერთი და მხოლოდ ერთი წრფე.
:::

:::theorem
მოსაზღვრე კუთხეების ბისექტრისები ურთიერთმართობულია. ვერტიკალური კუთხეების ბისექტრისები ერთ წრფეზე მდებარეობს.
:::

## დამტკიცება

ვთქვათ, $\angle1$ და $\angle3$ ვერტიკალურია, $\angle2$ კი ორივეს მოსაზღვრეა. მაშინ
$$\angle1+\angle2=180^\circ,\qquad \angle3+\angle2=180^\circ.$$
გამოვაკლოთ: $\angle1=\angle3$. $\blacksquare$

ბისექტრისებისთვის: თუ მოსაზღვრე კუთხეებია $\alpha$ და $\beta$, ბისექტრისებს შორის კუთხეა
$$\frac{\alpha}{2}+\frac{\beta}{2}=\frac{\alpha+\beta}{2}=\frac{180^\circ}{2}=90^\circ.$$

## ამოხსნილი მაგალითები

:::example მარტივი
ორი მოსაზღვრე კუთხე ერთმანეთისგან $40^\circ$-ით განსხვავდება. იპოვეთ ისინი.
:::solution
ვთქვათ, მცირე კუთხეა $x$, დიდი $x+40^\circ$. მაშინ $2x+40^\circ=180^\circ$, $x=70^\circ$.

**პასუხი:** $70^\circ$ და $110^\circ$.
:::
:::

:::example საშუალო
ორი წრფე იკვეთება. წარმოქმნილი ოთხი კუთხიდან სამის ჯამი $250^\circ$-ია. იპოვეთ ოთხივე კუთხე.
:::solution
ოთხივე კუთხის ჯამი $360^\circ$-ია (ორი წყვილი მოსაზღვრე კუთხე). მეოთხე კუთხე: $360^\circ-250^\circ=110^\circ$.

მისი ვერტიკალური კუთხეც $110^\circ$-ია, ორი დანარჩენი — $180^\circ-110^\circ=70^\circ$.

**პასუხი:** $110^\circ,\ 70^\circ,\ 110^\circ,\ 70^\circ$.
:::
:::

:::example რთული
$n$ წრფე ერთ წერტილზე გადის და სიბრტყეს $2n$ კუთხედ ყოფს. დაამტკიცეთ, რომ ამ კუთხეებიდან ერთ-ერთი მაინც არ აღემატება $\dfrac{180^\circ}{n}$-ს.
:::solution
ავიღოთ ერთ-ერთი წრფე. ის სიბრტყეს ორ ნახევრად ყოფს და ერთ მხარეს გაშლილ კუთხეს ქმნის. ამ გაშლილ კუთხეს დანარჩენი $n-1$ წრფე $n$ ნაწილად ყოფს.

ეს $n$ კუთხე ჯამში $180^\circ$-ია. თუ ყველა $\dfrac{180^\circ}{n}$-ზე მეტი იქნებოდა, ჯამი $180^\circ$-ს გადააჭარბებდა. ამიტომ ერთი მაინც $\le\dfrac{180^\circ}{n}$.

(მეორე ნახევრის $n$ კუთხე ამ კუთხეების ვერტიკალურია, ამიტომ ახალს არაფერს იძლევა.)

**პასუხი:** დამტკიცებულია.
:::
:::

## გავრცელებული შეცდომები

- **ყოველი საერთოგვერდიანი წყვილი მოსაზღვრეა.** არა: საჭიროა, რომ დანარჩენი ორი გვერდი ერთ წრფეს ქმნიდეს. მხოლოდ მაშინ არის ჯამი $180^\circ$.
- **ვერტიკალური = „ერთმანეთის ზემოთ“.** ვერტიკალური კუთხეები ერთმანეთის მოპირდაპირეა წვეროსთან, მათ ერთი მიმართულება არ აქვს.
- **ოთხი კუთხის ჯამი $180^\circ$.** ორი წრფის გადაკვეთისას ოთხივე კუთხის ჯამი $360^\circ$-ია.

## შეამოწმე თავი

:::check
იპოვეთ $37^\circ$-იანი კუთხის მოსაზღვრე კუთხე.
:::answer
$180^\circ-37^\circ=143^\circ$.
:::
:::

:::check
ორი წრფის გადაკვეთისას ერთი კუთხე სამჯერ მეტია მის მოსაზღვრე კუთხეზე. იპოვეთ ოთხივე კუთხე.
:::answer
$x+3x=180^\circ$, $x=45^\circ$. კუთხეები: $45^\circ,\ 135^\circ,\ 45^\circ,\ 135^\circ$.
:::
:::

:::check
რას უდრის კუთხე ორი ვერტიკალური კუთხის ბისექტრისებს შორის?
:::answer
$180^\circ$: ბისექტრისები ერთ წრფეს ქმნის.
:::
:::
