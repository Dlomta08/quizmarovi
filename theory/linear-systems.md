## მთავარი იდეა

ორი წრფივი განტოლება ორი უცნობით გეომეტრიულად ორი წრფეა. სისტემის ამონახსნი მათი საერთო წერტილია. ამიტომ შესაძლებელია სამი შემთხვევა: წრფეები იკვეთება (ერთი ამონახსნი), პარალელურია (არც ერთი) ან ემთხვევა (უსასრულოდ ბევრი). ალგებრულად ვცდილობთ ერთი უცნობის გამორიცხვას და ერთუცნობიან განტოლებაზე დაყვანას.

## განმარტებები და ფორმულები

:::definition
სისტემა
$$\begin{cases}a_1x+b_1y=c_1,\\ a_2x+b_2y=c_2\end{cases}$$
**ამონახსნი** არის რიცხვთა წყვილი $(x;y)$, რომელიც ორივე განტოლებას აკმაყოფილებს.
:::

:::formula ამოხსნის ხერხები
- **ჩასმის ხერხი:** ერთი განტოლებიდან გამოვსახავთ ერთ უცნობს და ვსვამთ მეორეში.
- **შეკრების ხერხი:** განტოლებებს ვამრავლებთ ისეთ რიცხვებზე, რომ შეკრებისას ერთი უცნობი გაქრეს.
:::

:::theorem ამონახსნების რაოდენობა
(კოეფიციენტები არანულოვანია)
- $\dfrac{a_1}{a_2}\neq\dfrac{b_1}{b_2}$ — ერთადერთი ამონახსნი;
- $\dfrac{a_1}{a_2}=\dfrac{b_1}{b_2}\neq\dfrac{c_1}{c_2}$ — ამონახსნი არ არის;
- $\dfrac{a_1}{a_2}=\dfrac{b_1}{b_2}=\dfrac{c_1}{c_2}$ — უსასრულოდ ბევრი ამონახსნი.

ზოგადად: ერთადერთი ამონახსნი არის მაშინ და მხოლოდ მაშინ, როცა $a_1b_2-a_2b_1\neq0$.
:::

## დამტკიცება

გამოვრიცხოთ $y$: პირველი განტოლება გავამრავლოთ $b_2$-ზე, მეორე $b_1$-ზე და გამოვაკლოთ:
$$(a_1b_2-a_2b_1)\,x=c_1b_2-c_2b_1.$$
ანალოგიურად $(a_1b_2-a_2b_1)\,y=a_1c_2-a_2c_1$.

თუ $\Delta=a_1b_2-a_2b_1\neq0$, ორივე უცნობი ცალსახად განისაზღვრება:
$$x=\frac{c_1b_2-c_2b_1}{\Delta},\qquad y=\frac{a_1c_2-a_2c_1}{\Delta}.$$
თუ $\Delta=0$, ეს განტოლებები სახისაა $0\cdot x=\ldots$ — ამონახსნი ან არ არის, ან უსასრულოდ ბევრია (წრფივი განტოლების სამი შემთხვევა). $\blacksquare$

## ამოხსნილი მაგალითები

:::example მარტივი
ამოხსენით $\begin{cases}x+y=7,\\ x-y=1.\end{cases}$
:::solution
შევკრიბოთ: $2x=8$, $x=4$. მაშინ $y=7-4=3$.

**პასუხი:** $(4;\,3)$.
:::
:::

:::example საშუალო
ამოხსენით $\begin{cases}3x+2y=12,\\ 5x-3y=1.\end{cases}$
:::solution
პირველი გავამრავლოთ $3$-ზე, მეორე $2$-ზე:
$$9x+6y=36,\qquad 10x-6y=2.$$
შევკრიბოთ: $19x=38$, $x=2$. პირველიდან $2y=12-6$, $y=3$.

შემოწმება მეორე განტოლებაში: $10-9=1$.

**პასუხი:** $(2;\,3)$.
:::
:::

:::example რთული
$a$-ს რა მნიშვნელობებისთვის აქვს სისტემას $\begin{cases}ax+2y=3,\\ 2x+ay=a+1\end{cases}$ ერთადერთი ამონახსნი, არც ერთი, უსასრულოდ ბევრი?
:::solution
$\Delta=a\cdot a-2\cdot2=a^2-4$.

- $a\neq\pm2$: $\Delta\neq0$ — ერთადერთი ამონახსნი.
- $a=2$: $2x+2y=3$ და $2x+2y=3$ — ერთი და იგივე განტოლება, უსასრულოდ ბევრი ამონახსნი.
- $a=-2$: $-2x+2y=3$ და $2x-2y=-1$, ანუ $-2x+2y=1$. მარცხენა მხარეები ტოლია, მარჯვენა — არა: ამონახსნი არ არის.

**პასუხი:** $a\neq\pm2$ — ერთი; $a=-2$ — არც ერთი; $a=2$ — უსასრულოდ ბევრი.
:::
:::

## გავრცელებული შეცდომები

- **ნიშანი გამოკლებისას.** განტოლებების გამოკლებისას მეორე განტოლების **ყველა** წევრს ნიშანი ეცვლება.
- **მეორე უცნობის დავიწყება.** პასუხი წყვილია: $(x;y)$.
- **შემოწმება მხოლოდ ერთ განტოლებაში.** ამონახსნი ორივე განტოლებაში უნდა შემოწმდეს.
- **პარამეტრის შემთხვევების გამოტოვება.** როცა $\Delta=0$, სისტემას ცალკე ვამოწმებთ — ის ან უამონახსნოა, ან უსასრულოდ ბევრი ამონახსნი აქვს.

## შეამოწმე თავი

:::check
ამოხსენით $\begin{cases}x=2y,\\ x+y=9.\end{cases}$
:::answer
$3y=9$, $y=3$, $x=6$: $(6;\,3)$.
:::
:::

:::check
რამდენი ამონახსნი აქვს სისტემას $\begin{cases}x+y=1,\\ 2x+2y=3?\end{cases}$
:::answer
არც ერთი: მეორე განტოლება ნიშნავს $x+y=1{,}5$.
:::
:::

:::check
რას ნიშნავს გეომეტრიულად, რომ სისტემას ერთადერთი ამონახსნი აქვს?
:::answer
ორი წრფე ერთ წერტილში იკვეთება.
:::
:::
