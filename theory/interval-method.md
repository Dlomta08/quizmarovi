## მთავარი იდეა

ნამრავლის ან წილადის ნიშანი დამოკიდებულია მხოლოდ მამრავლების ნიშნებზე. წრფივი მამრავლი $(x-a)$ ნიშანს იცვლის მხოლოდ $a$ წერტილში. ამიტომ რიცხვით ღერძს ვყოფთ ამ წერტილებით და თითოეულ შუალედზე ნიშანი მუდმივია. ასე ნებისმიერი რაციონალური უტოლობა იხსნება ერთი სქემით — ნიშნების „ხაზით“.

## განმარტებები და ფორმულები

:::formula ინტერვალთა მეთოდი
$\dfrac{P(x)}{Q(x)}\vee0$ სახის უტოლობისთვის ($\vee$ — ერთ-ერთი ნიშანი $>,<,\ge,\le$):
1. ყველა წევრი გადავიტანოთ ერთ მხარეს და მივიყვანოთ ერთ წილადზე.
2. $P$ და $Q$ დავშალოთ მამრავლებად.
3. მოვნიშნოთ ღერძზე მრიცხველის ნულები (შევსებული წერტილით, თუ $\ge$ ან $\le$) და მნიშვნელის ნულები (ყოველთვის **ცარიელი** წერტილით).
4. დავადგინოთ ნიშანი უკიდურეს მარჯვენა შუალედზე და გავიაროთ მარცხნივ: **კენტი** ჯერადობის წერტილში ნიშანი იცვლება, **ლუწი** ჯერადობისაში — არა.
5. ავიღოთ საჭირო ნიშნის შუალედები.
:::

:::definition
წერტილის **ჯერადობა** არის ის ხარისხი, რომლითაც შესაბამისი მამრავლი შედის: $(x-1)^2$-ში წერტილი $1$ ორჯერადია.
:::

:::note
უტოლობის მნიშვნელზე გამრავლება არ შეიძლება, თუ მისი ნიშანი უცნობია. ამიტომ ყველაფერს ერთ მხარეს ვაგროვებთ და ნულთან ვადარებთ.
:::

## დამტკიცება

მამრავლი $(x-a)^k$ დადებითია, როცა $x>a$. როცა $x<a$, მისი ნიშანი $(-1)^k$-ია: კენტი $k$-სთვის უარყოფითი, ლუწისთვის — დადებითი. ყველაზე მარჯვენა შუალედზე ყველა $(x-a_i)$ დადებითია, ამიტომ ნიშანი უფროსი კოეფიციენტების ნიშნით განისაზღვრება.

$a_i$ წერტილის გავლისას ნიშანს იცვლის მხოლოდ ერთი მამრავლი, $(x-a_i)^{k_i}$ — და მხოლოდ მაშინ, როცა $k_i$ კენტია. დანარჩენი მამრავლები ამ წერტილის მახლობლად ნიშანს ინარჩუნებს. ამიტომ წესი „კენტზე იცვლება, ლუწზე არა“ სწორია. $\blacksquare$

## ამოხსნილი მაგალითები

:::example მარტივი
ამოხსენით $(x-1)(x+2)(x-4)\ge0$.
:::solution
წერტილები $-2,\ 1,\ 4$ (ყველა ერთჯერადი). $x>4$-ზე ნიშანი $+$, შემდეგ მონაცვლეობით: $(1;4)$ — $-$, $(-2;1)$ — $+$, $x<-2$ — $-$.

**პასუხი:** $x\in[-2;\,1]\cup[4;\,+\infty)$.
:::
:::

:::example საშუალო
ამოხსენით $\dfrac{x+3}{x-2}\le1$.
:::solution
გადავიტანოთ $1$ და მივიყვანოთ საერთო მნიშვნელზე:
$$\frac{x+3-(x-2)}{x-2}\le0\iff\frac{5}{x-2}\le0.$$
მრიცხველი დადებითია, წილადი ნულს ვერ უდრის, ამიტომ საჭიროა $x-2<0$.

**პასუხი:** $x\in(-\infty;\,2)$.
:::
:::

:::example რთული
ამოხსენით $\dfrac{(x-1)^2(x+2)}{x-3}<0$.
:::solution
წერტილები: $-2$ (ერთჯერადი), $1$ (ორჯერადი), $3$ (მნიშვნელი, ცარიელი).

$x>3$: $+$. $3$-ის გავლისას იცვლება: $(1;3)$ — $-$. $1$ ორჯერადია, ნიშანი არ იცვლება: $(-2;1)$ — $-$. $-2$-ის გავლისას იცვლება: $x<-2$ — $+$.

უტოლობა მკაცრია, ამიტომ $x=1$ (სადაც გამოსახულება $0$-ია) არ შედის.

**პასუხი:** $x\in(-2;\,1)\cup(1;\,3)$.
:::
:::

## გავრცელებული შეცდომები

- **მნიშვნელზე გამრავლება.** $\frac{x+3}{x-2}\le1\Rightarrow x+3\le x-2$ არასწორია: $x-2$ შეიძლება უარყოფითი იყოს.
- **მნიშვნელის ნულის ჩართვა.** $\ge$ ან $\le$-ის შემთხვევაშიც მნიშვნელის ნულები პასუხში არ შედის.
- **ნიშნის მონაცვლეობა ლუწ წერტილზე.** $(x-1)^2$-ის წერტილში ნიშანი არ იცვლება.
- **უარყოფითი კოეფიციენტი.** $(2-x)$ ჯობს ჩავწეროთ როგორც $-(x-2)$; თორემ მარჯვენა შუალედის ნიშანი შეცდომით განისაზღვრება.

## შეამოწმე თავი

:::check
ამოხსენით $\dfrac1x<1$.
:::answer
$\frac{1-x}{x}<0\iff\frac{x-1}{x}>0$: $x<0$ ან $x>1$.
:::
:::

:::check
ამოხსენით $\dfrac{x-2}{x+1}\ge0$.
:::answer
$x\in(-\infty;\,-1)\cup[2;\,+\infty)$.
:::
:::

:::check
ამოხსენით $x^2(x-5)\le0$.
:::answer
$x\in(-\infty;\,5]$ ($x=0$ ორჯერადია, ნიშანი არ იცვლება, და ის ისედაც შედის).
:::
:::
