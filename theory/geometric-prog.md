## მთავარი იდეა

გეომეტრიულ პროგრესიაში ყოველი წევრი წინას ერთსა და იმავე რიცხვზე გამრავლებით მიიღება. ეს არის „მრავლობითი“ ზრდა: რთული პროცენტი, გამრავლება, დაშლა. პირველი $n$ წევრის ჯამი ერთი ხრიკით ითვლება — ჯამს ვამრავლებთ მნიშვნელზე და ვაკლებთ საწყისს. თუ $|q|<1$, წევრები სწრაფად მცირდება და უსასრულო ჯამიც სასრულ რიცხვს უდრის.

## განმარტებები და ფორმულები

:::definition
არანულოვანი რიცხვების მიმდევრობას $(b_n)$ ეწოდება **გეომეტრიული პროგრესია**, თუ $b_{n+1}=b_n\cdot q$ ყოველი $n$-სთვის, სადაც $q\neq0$ — პროგრესიის **მნიშვნელი**.
:::

:::formula $n$-ური წევრი
$$b_n=b_1q^{n-1}.$$
:::

:::theorem დამახასიათებელი თვისება
$b_n^2=b_{n-1}b_{n+1}$; დადებითი წევრების შემთხვევაში ყოველი წევრი მეზობლების საშუალო გეომეტრიულია. ზოგადად: თუ $m+n=p+q$ (ინდექსები), მაშინ $b_mb_n=b_pb_q$.
:::

:::formula პირველი $n$ წევრის ჯამი
$$S_n=\frac{b_1(q^n-1)}{q-1}\quad(q\neq1),\qquad S_n=nb_1\quad(q=1).$$
:::

:::formula უსასრულოდ კლებადი პროგრესია
თუ $|q|<1$, ყველა წევრის ჯამი
$$S=\frac{b_1}{1-q}.$$
:::

## დამტკიცება

$$S_n=b_1+b_1q+\ldots+b_1q^{n-1},\qquad qS_n=b_1q+b_1q^2+\ldots+b_1q^{n}.$$
გამოვაკლოთ: შუა წევრები ბათილდება, რჩება $qS_n-S_n=b_1q^n-b_1$. თუ $q\neq1$:
$$S_n=\frac{b_1(q^n-1)}{q-1}.\ \blacksquare$$

უსასრულო ჯამი: როცა $|q|<1$, $q^n$ ნულს უახლოვდება $n$-ის ზრდისას, ამიტომ $S_n\to\frac{b_1(0-1)}{q-1}=\frac{b_1}{1-q}$.

## ამოხსნილი მაგალითები

:::example მარტივი
$b_1=3$, $q=2$. იპოვეთ $b_6$ და $S_6$.
:::solution
$b_6=3\cdot2^5=96$. $S_6=\dfrac{3(2^6-1)}{2-1}=189$.

**პასუხი:** $96$ და $189$.
:::
:::

:::example საშუალო
გადააქციეთ $0{,}(36)$ ჩვეულებრივ წილადად.
:::solution
$0{,}363636\ldots=\dfrac{36}{100}+\dfrac{36}{100^2}+\ldots$ — უსასრულოდ კლებადი პროგრესია $b_1=\frac{36}{100}$, $q=\frac1{100}$.
$$S=\frac{\frac{36}{100}}{1-\frac1{100}}=\frac{36}{99}=\frac4{11}.$$
**პასუხი:** $\dfrac4{11}$.
:::
:::

:::example რთული
სამი რიცხვი გეომეტრიულ პროგრესიას ქმნის, მათი ჯამია $21$. თუ მესამეს გამოვაკლებთ $9$-ს, მიიღება არითმეტიკული პროგრესია. იპოვეთ რიცხვები.
:::solution
რიცხვები $b,\ bq,\ bq^2$. პირობები:
$$b(1+q+q^2)=21,\qquad 2bq=b+bq^2-9.$$
მეორედან $b(q-1)^2=9$, ანუ $b(q^2-2q+1)=9$. გამოვაკლოთ პირველს: $3bq=12$, $bq=4$.

ჩავსვათ $b=\frac4q$ პირველში: $\frac4q(1+q+q^2)=21\iff4q^2-17q+4=0$, $q=4$ ან $q=\frac14$.
- $q=4$: $1,\ 4,\ 16$ (შემოწმება: $1,4,7$ — არითმეტიკულია).
- $q=\frac14$: $16,\ 4,\ 1$ (შემოწმება: $16,4,-8$ — არითმეტიკულია, $d=-12$).

**პასუხი:** $1,4,16$ ან $16,4,1$.
:::
:::

## გავრცელებული შეცდომები

- **$b_n=b_1q^n$.** სწორია $q^{n-1}$.
- **უსასრულო ჯამი $|q|\ge1$-სთვის.** $\frac{b_1}{1-q}$ მხოლოდ $|q|<1$-ზე მუშაობს: $1+2+4+\ldots$ უსასრულოა.
- **უარყოფითი მნიშვნელი.** $q<0$-ზე წევრების ნიშნები მონაცვლეობს; $b_n^2=b_{n-1}b_{n+1}$-დან $b_n=\pm\sqrt{\ldots}$ — ორივე ვარიანტი შესამოწმებელია.
- **„$q=0$“.** გეომეტრიულ პროგრესიაში წევრები და მნიშვნელი ნულისგან განსხვავდება.

## შეამოწმე თავი

:::check
$2,\ x,\ 18$ დადებითი წევრების გეომეტრიული პროგრესიაა. იპოვეთ $x$.
:::answer
$x^2=36$, $x=6$.
:::
:::

:::check
იპოვეთ $1+\dfrac12+\dfrac14+\ldots$
:::answer
$\frac{1}{1-\frac12}=2$.
:::
:::

:::check
იპოვეთ $1+2+4+\ldots+2^{9}$.
:::answer
$\frac{2^{10}-1}{2-1}=1023$.
:::
:::
