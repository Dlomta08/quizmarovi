## მთავარი იდეა

კვადრატული ფესვი კვადრატში აყვანის საპირისპირო მოქმედებაა. $x^2=a$ განტოლებას დადებითი $a$-სთვის ორი ამონახსნი აქვს, ამიტომ $\sqrt a$-ით აღინიშნება მხოლოდ არაუარყოფითი. სწორედ აქედან მოდის ყველაზე ხშირი შეცდომა: $\sqrt{a^2}$ არის $|a|$ და არა $a$. ფესვებთან მუშაობა საჭიროა ირაციონალურ განტოლებებში, გეომეტრიაში და კვადრატული განტოლების ფორმულაში.

## განმარტებები და ფორმულები

:::definition
$a\ge0$ რიცხვის **არითმეტიკული კვადრატული ფესვი** $\sqrt a$ არის ისეთი **არაუარყოფითი** რიცხვი, რომლის კვადრატი $a$-ს ტოლია. უარყოფითი რიცხვიდან კვადრატული ფესვი (ნამდვილ რიცხვებში) არ არსებობს.
:::

:::theorem ძირითადი თვისებები
$$(\sqrt a)^2=a\ (a\ge0),\qquad \sqrt{a^2}=|a|,$$
$$\sqrt{ab}=\sqrt a\,\sqrt b,\qquad \sqrt{\frac ab}=\frac{\sqrt a}{\sqrt b}\qquad(a\ge0,\ b>0).$$
:::

:::formula გარდაქმნები
- **მამრავლის გატანა:** $\sqrt{a^2b}=|a|\sqrt b$; მაგალითად $\sqrt{50}=5\sqrt2$.
- **მნიშვნელში ირაციონალობის მოშორება:** $\dfrac{1}{\sqrt a-\sqrt b}=\dfrac{\sqrt a+\sqrt b}{a-b}$.
- **რთული ფესვი:** თუ $x,y\ge0$, $x+y=a$ და $xy=b$, მაშინ $\sqrt{a\pm2\sqrt b}=|\sqrt x\pm\sqrt y|$.
:::

:::theorem
$\sqrt2$ ირაციონალური რიცხვია: ის არ ჩაიწერება $\dfrac pq$ წილადად მთელი $p$ და $q$-თი.
:::

## დამტკიცება

**$\sqrt2$-ის ირაციონალობა.** დავუშვათ, $\sqrt2=\dfrac pq$, სადაც წილადი შეუკვეცავია. მაშინ $p^2=2q^2$, ანუ $p^2$ ლუწია. მაშინ $p$-იც ლუწია (კენტის კვადრატი კენტია): $p=2k$. ჩავსვათ: $4k^2=2q^2$, $q^2=2k^2$ — ანუ $q$-იც ლუწია. $p$ და $q$ ორივე ლუწია, ეს კი ეწინააღმდეგება შეუკვეცაობას. $\blacksquare$

**$\sqrt{ab}=\sqrt a\sqrt b$.** მარჯვენა მხარე არაუარყოფითია და მისი კვადრატია $(\sqrt a)^2(\sqrt b)^2=ab$. განმარტებით, ეს სწორედ $\sqrt{ab}$-ა.

## ამოხსნილი მაგალითები

:::example მარტივი
გამოთვალეთ $\sqrt{50}+\sqrt{18}-\sqrt8$.
:::solution
$\sqrt{50}=5\sqrt2$, $\sqrt{18}=3\sqrt2$, $\sqrt8=2\sqrt2$. ჯამი: $(5+3-2)\sqrt2=6\sqrt2$.

**პასუხი:** $6\sqrt2$.
:::
:::

:::example საშუალო
მოიშორეთ ირაციონალობა მნიშვნელში: $\dfrac{1}{\sqrt5-\sqrt3}$.
:::solution
გავამრავლოთ მრიცხველი და მნიშვნელი $\sqrt5+\sqrt3$-ზე (შეუღლებულზე):
$$\frac{\sqrt5+\sqrt3}{(\sqrt5)^2-(\sqrt3)^2}=\frac{\sqrt5+\sqrt3}{2}.$$
**პასუხი:** $\dfrac{\sqrt5+\sqrt3}2$.
:::
:::

:::example რთული
გამოთვალეთ $\sqrt{7+4\sqrt3}+\sqrt{7-4\sqrt3}$.
:::solution
$4\sqrt3=2\sqrt{12}$. ვეძებთ $x+y=7$, $xy=12$: $x=4$, $y=3$. ამიტომ
$$7\pm4\sqrt3=(\sqrt4\pm\sqrt3)^2=(2\pm\sqrt3)^2.$$
$2-\sqrt3>0$, ამიტომ მოდული საჭირო აღარ არის:
$$\sqrt{7+4\sqrt3}+\sqrt{7-4\sqrt3}=(2+\sqrt3)+(2-\sqrt3)=4.$$
**პასუხი:** $4$.
:::
:::

## გავრცელებული შეცდომები

- **$\sqrt{a^2}=a$.** სწორია $\sqrt{a^2}=|a|$. მაგალითად $\sqrt{(-3)^2}=3$.
- **ჯამის ფესვი.** $\sqrt{a+b}\neq\sqrt a+\sqrt b$: $\sqrt{9+16}=5$, ხოლო $3+4=7$.
- **უარყოფითი მამრავლები.** $\sqrt{(-4)(-9)}=6$, მაგრამ ჩანაწერი $\sqrt{-4}\cdot\sqrt{-9}$ აზრს მოკლებულია. ნამრავლის წესი მხოლოდ არაუარყოფითებისთვისაა.
- **$\sqrt{x^2}$ ცვლადებით.** $\sqrt{x^2-6x+9}=|x-3|$ და არა $x-3$.

## შეამოწმე თავი

:::check
გამოთვალეთ $\sqrt{(1-\sqrt2)^2}$.
:::answer
$|1-\sqrt2|=\sqrt2-1$, რადგან $\sqrt2>1$.
:::
:::

:::check
გამოთვალეთ $\sqrt{0{,}0009}$.
:::answer
$0{,}03$, რადგან $0{,}03^2=0{,}0009$.
:::
:::

:::check
რომელია მეტი: $2\sqrt3$ თუ $3\sqrt2$?
:::answer
$2\sqrt3=\sqrt{12}$, $3\sqrt2=\sqrt{18}$. მეტია $3\sqrt2$.
:::
:::
