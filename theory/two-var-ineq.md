## მთავარი იდეა

ორუცნობიანი უტოლობის ამონახსნი არის წერტილების სიმრავლე კოორდინატთა სიბრტყეზე. შესაბამისი ტოლობა არის წირი — საზღვარი, რომელიც სიბრტყეს ნაწილებად ყოფს. ყოველ ნაწილში უტოლობა ან ყველგან სრულდება, ან არსად. ამიტომ საკმარისია საზღვრის აგება და ერთი „საცდელი“ წერტილის შემოწმება.

## განმარტებები და ფორმულები

:::definition
$F(x,y)>0$ უტოლობის **ამონახსნი** არის ყველა წერტილი $(x;y)$, რომლისთვისაც უტოლობა ჭეშმარიტია. სისტემის ამონახსნი ამონახსნების თანაკვეთაა.
:::

:::theorem წრფივი უტოლობა
წრფე $ax+by+c=0$ სიბრტყეს ორ ნახევარსიბრტყედ ყოფს. ერთში $ax+by+c>0$, მეორეში $ax+by+c<0$. კერძოდ, $y>kx+m$ არის წრფის **ზემოთ** მდებარე ნახევარსიბრტყე, $y<kx+m$ — **ქვემოთ**.
:::

:::formula ხშირი არეები
- $x^2+y^2\le r^2$ — წრე ცენტრით სათავეში (საზღვრით); $x^2+y^2>r^2$ — მის გარეთ.
- $y\ge x^2$ — პარაბოლის „შიგნით“ (ზემოთ).
- $|x|+|y|\le a$ — კვადრატი წვეროებით $(\pm a;0)$, $(0;\pm a)$.
- $y\ge|x|$ — კუთხე, რომლის გვერდებია $y=x$ და $y=-x$ ($y\ge0$ ნაწილში).
:::

:::formula ამოხსნის გეგმა
1. ავაგოთ საზღვარი (ტოლობის გრაფიკი): მკაცრ უტოლობაში — წყვეტილი ხაზით, არამკაცრში — უწყვეტით.
2. ავიღოთ საცდელი წერტილი, რომელიც საზღვარზე არ დევს (ხშირად $(0;0)$) და შევამოწმოთ.
3. დავშტრიხოთ შესაბამისი ნაწილი; სისტემისთვის — თანაკვეთა.
:::

## დამტკიცება

ვთქვათ $b>0$. მაშინ $ax+by+c>0\iff y>-\dfrac abx-\dfrac cb$. ფიქსირებული $x$-ისთვის ეს არის ყველა $y$, რომელიც მეტია წრფის წერტილის ორდინატაზე, ანუ ვერტიკალური სხივი წრფის ზემოთ. ყველა $x$-ისთვის ასეთი სხივები ქმნის ზედა ნახევარსიბრტყეს. ($b<0$-ის შემთხვევა — ქვედა; $b=0$-ის — მარჯვენა ან მარცხენა, ვერტიკალური წრფის მიმართ.) $\blacksquare$

## ამოხსნილი მაგალითები

:::example მარტივი
აკმაყოფილებს თუ არა $(1;2)$ წერტილი $3x-y<2$ უტოლობას? აღწერეთ ამონახსნთა სიმრავლე.
:::solution
$3-2=1<2$ — აკმაყოფილებს. $3x-y<2\iff y>3x-2$: წრფის $y=3x-2$ ზემოთ მდებარე ღია ნახევარსიბრტყე (წრფე არ შედის).
:::
:::

:::example საშუალო
იპოვეთ სისტემის $x\ge0$, $y\ge0$, $x+2y\le4$ ამონახსნთა არის ფართობი.
:::solution
ეს სამკუთხედია წვეროებით $(0;0)$, $(4;0)$, $(0;2)$: პირველ მეოთხედში, წრფის $x+2y=4$ ქვემოთ.

ფართობი: $\frac12\cdot4\cdot2=4$.

**პასუხი:** $4$.
:::
:::

:::example რთული
იპოვეთ სისტემის $x^2+y^2\le4$, $y\ge|x|$ ამონახსნთა არის ფართობი.
:::solution
$y\ge|x|$ არის კუთხე $y=x$ და $y=-x$ სხივებს შორის, ზემოთ. ეს სხივები ერთმანეთის მართობულია, ამიტომ კუთხე $90^\circ$-ია. წრე $x^2+y^2\le4$ ($r=2$) ამ კუთხით იჭრება $90^\circ$-იან სექტორად — წრის მეოთხედად.

ფართობი: $\frac14\cdot\pi\cdot2^2=\pi$.

**პასუხი:** $\pi$.
:::
:::

## გავრცელებული შეცდომები

- **„ზემოთ“ და „ქვემოთ“ $y$-ის გამოსახვის გარეშე.** $-y>2x$ ნიშნავს $y<-2x$ — უარყოფითზე გამრავლება ნიშანს ცვლის.
- **საზღვრის ჩართვა.** მკაცრ უტოლობაში საზღვარი არ შედის, არამკაცრში — შედის.
- **საცდელი წერტილი საზღვარზე.** თუ $(0;0)$ საზღვარზე დევს, სხვა წერტილი ავიღოთ.
- **სისტემა და ერთობლიობა.** სისტემა — თანაკვეთა, ერთობლიობა („ან“) — გაერთიანება.

## შეამოწმე თავი

:::check
აღწერეთ $x^2+y^2>1$ უტოლობის ამონახსნთა სიმრავლე.
:::answer
ერთეულოვანი წრეწირის გარეთ მდებარე წერტილები (წრეწირი არ შედის).
:::
:::

:::check
იპოვეთ $|x|\le1$, $|y|\le2$ სისტემის ამონახსნთა არის ფართობი.
:::answer
მართკუთხედი $2\times4$, ფართობი $8$.
:::
:::

:::check
იპოვეთ $|x|+|y|\le2$ არის ფართობი.
:::answer
კვადრატი, რომლის დიაგონალები $4$-ია: $\frac{4\cdot4}{2}=8$.
:::
:::
