## მთავარი იდეა

ამოზნექილი $n$-კუთხედი ერთი წვეროდან გავლებული დიაგონალებით $n-2$ სამკუთხედად იყოფა. აქედან მისი შიგა კუთხეების ჯამი $(n-2)\cdot180^\circ$-ია. გარე კუთხეების ჯამი კი არ არის დამოკიდებული $n$-ზე: ის ყოველთვის $360^\circ$-ია.

მეორე ხშირი თემა დიაგონალების დათვლაა: ყოველი წვეროდან გამოდის $n-3$ დიაგონალი.

## განმარტებები და ფორმულები

:::definition
**მრავალკუთხედი** არის შეკრული ტეხილით შემოსაზღვრული ფიგურა, რომლის მეზობელი რგოლები ერთ წრფეზე არ მდებარეობს. **დიაგონალი** აერთებს ორ არამეზობელ წვეროს. მრავალკუთხედი **ამოზნექილია**, თუ ის მთლიანად მდებარეობს ყოველი გვერდის შემცველი წრფის ერთ მხარეს.
:::

:::formula
ამოზნექილი $n$-კუთხედისთვის:
$$\text{შიგა კუთხეების ჯამი}=(n-2)\cdot180^\circ,\qquad \text{გარე კუთხეების ჯამი}=360^\circ,$$
$$\text{დიაგონალების რაოდენობა}=\frac{n(n-3)}{2}.$$
:::

:::note
ამოზნექილ მრავალკუთხედში ყოველი შიგა კუთხე $180^\circ$-ზე ნაკლებია. გარე კუთხე აქაც შიგა კუთხის მოსაზღვრეა: $180^\circ$ მინუს შიგა კუთხე.
:::

## დამტკიცება

**კუთხეების ჯამი.** ერთი წვეროდან გავავლოთ ყველა დიაგონალი. ისინი $n$-კუთხედს $n-2$ სამკუთხედად ყოფს, რომელთა კუთხეები ერთად ზუსტად მრავალკუთხედის კუთხეებს ავსებს. ჯამი: $(n-2)\cdot180^\circ$.

**გარე კუთხეები.** ყოველ წვეროსთან შიგა და გარე კუთხის ჯამი $180^\circ$-ია, ამიტომ ყველა ერთად $n\cdot180^\circ$. გამოვაკლოთ შიგა კუთხეები: $n\cdot180^\circ-(n-2)\cdot180^\circ=360^\circ$.

**დიაგონალები.** ყოველი წვეროდან $n-3$ დიაგონალი გამოდის (არა საკუთარ თავთან და არა ორ მეზობელთან). სულ $n(n-3)$, მაგრამ ყოველი დიაგონალი ორჯერ დავთვალეთ (ორივე ბოლოდან). $\blacksquare$

## ამოხსნილი მაგალითები

:::example მარტივი
იპოვეთ ექვსკუთხედის შიგა კუთხეების ჯამი და წესიერი ექვსკუთხედის თითოეული კუთხე.
:::solution
$(6-2)\cdot180^\circ=720^\circ$. წესიერში ყველა კუთხე ტოლია: $\dfrac{720^\circ}{6}=120^\circ$.

**პასუხი:** $720^\circ$ და $120^\circ$.
:::
:::

:::example საშუალო
ამოზნექილი მრავალკუთხედის შიგა კუთხეების ჯამი $1980^\circ$-ია. რამდენი დიაგონალი აქვს მას?
:::solution
$(n-2)\cdot180^\circ=1980^\circ$, $n-2=11$, $n=13$.

დიაგონალები: $\dfrac{13\cdot10}{2}=65$.

**პასუხი:** $65$.
:::
:::

:::example რთული
რამდენი მახვილი შიგა კუთხე შეიძლება ჰქონდეს ამოზნექილ მრავალკუთხედს მაქსიმუმ?
:::solution
თუ შიგა კუთხე მახვილია, მისი გარე კუთხე $90^\circ$-ზე მეტია. ოთხი ასეთი კუთხის გარე კუთხეების ჯამი $360^\circ$-ს გადააჭარბებდა, დანარჩენი გარე კუთხეები კი დადებითია. ეს შეუძლებელია, რადგან გარე კუთხეების ჯამი ზუსტად $360^\circ$-ია.

სამი მახვილი კუთხე შესაძლებელია: მაგალითად, მახვილკუთხა სამკუთხედში.

**პასუხი:** $3$.
:::
:::

## გავრცელებული შეცდომები

- **$n\cdot180^\circ$.** შიგა კუთხეების ჯამი $(n-2)\cdot180^\circ$-ია; $n\cdot180^\circ$ შიგა და გარე კუთხეების ერთობლივი ჯამია.
- **დიაგონალები $n(n-3)$.** არ დაგავიწყდეთ $2$-ზე გაყოფა — ყოველი დიაგონალი ორ წვეროს აერთებს.
- **გარე კუთხეების ჯამი იზრდება $n$-თან ერთად.** არა, ის ყოველთვის $360^\circ$-ია.

## შეამოწმე თავი

:::check
რამდენკუთხედს აქვს $20$ დიაგონალი?
:::answer
$n(n-3)=40$, $n=8$.
:::
:::

:::check
წესიერი მრავალკუთხედის გარე კუთხე $24^\circ$-ია. რამდენი გვერდი აქვს მას?
:::answer
$\dfrac{360^\circ}{24^\circ}=15$.
:::
:::

:::check
შეიძლება თუ არა, ამოზნექილი მრავალკუთხედის ყველა შიგა კუთხე $100^\circ$ იყოს?
:::answer
არა: $(n-2)\cdot180=100n$ გვაძლევს $n=4.5$, მთელი არ არის.
:::
:::
