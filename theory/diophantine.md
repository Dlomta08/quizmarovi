## მთავარი იდეა

როცა ამონახსნს მხოლოდ მთელ (ან ნატურალურ) რიცხვებში ვეძებთ, ერთ განტოლებას შეიძლება ჰქონდეს სასრული რაოდენობის ამონახსნი, არც ერთი ან უსასრულოდ ბევრი. ძირითადი ხერხები სამია: **მამრავლებად დაშლა** (ნამრავლი უდრის რიცხვს — გადავარჩევთ გამყოფებს), **ნაშთები** (ვაჩვენებთ, რომ მხარეები სხვადასხვა ნაშთს იძლევა) და **შეფასება** (უცნობს ვზღუდავთ და ვარიანტებს ვამოწმებთ).

## განმარტებები და ფორმულები

:::definition
**დიოფანტეს განტოლება** არის განტოლება, რომლის ამონახსნებს მთელ რიცხვებში ვეძებთ. უმარტივესია წრფივი: $ax+by=c$, სადაც $a,b,c$ მთელებია.
:::

:::theorem წრფივი განტოლება მთელ რიცხვებში
ვთქვათ $d=\gcd(a,b)$.
- $ax+by=c$ განტოლებას მთელი ამონახსნი აქვს მაშინ და მხოლოდ მაშინ, როცა $d\mid c$.
- თუ $(x_0;y_0)$ ერთ-ერთი ამონახსნია, ყველა ამონახსნი ასეთია:
$$x=x_0+\frac bd\,t,\qquad y=y_0-\frac ad\,t,\qquad t\in\mathbb Z.$$
:::

:::formula მამრავლებად დაშლის ხერხი
$xy+px+qy=r$ სახის განტოლება გარდაიქმნება $(x+q)(y+p)=r+pq$ სახეზე. მარჯვენა მხარე ფიქსირებული რიცხვია — ვარჩევთ მის ყველა (დადებით და უარყოფით) გამყოფს.
:::

:::formula ნაშთების ხერხი
სრული კვადრატი $4$-ზე გაყოფისას იძლევა მხოლოდ $0$ ან $1$ ნაშთს, $3$-ზე გაყოფისას — $0$ ან $1$-ს. ასე ხშირად მტკიცდება, რომ ამონახსნი არ არსებობს.
:::

## დამტკიცება

**ზოგადი ამონახსნი.** ვთქვათ $ax+by=c$ და $ax_0+by_0=c$. გამოვაკლოთ: $a(x-x_0)=-b(y-y_0)$. გავყოთ $d$-ზე: $a'(x-x_0)=-b'(y-y_0)$, სადაც $a'=\frac ad$, $b'=\frac bd$ ურთიერთმარტივია. მარცხენა მხარე იყოფა $b'$-ზე, $a'$ კი $b'$-თან ურთიერთმარტივია, ამიტომ $b'\mid x-x_0$, ანუ $x-x_0=b't$. ჩავსვათ: $y-y_0=-a't$. პირიქით, ასეთი ყოველი წყვილი ამონახსნია (ჩასმით მოწმდება). $\blacksquare$

## ამოხსნილი მაგალითები

:::example მარტივი
ამოხსენით ნატურალურ რიცხვებში $3x+5y=31$.
:::solution
ერთი ამონახსნი შერჩევით: $x=2$, $y=5$ ($6+25=31$). ზოგადი: $x=2+5t$, $y=5-3t$.

ნატურალურობის პირობა: $2+5t\ge1$ და $5-3t\ge1$, ანუ $t\ge0$ (მთელი) და $t\le1$. ასე $t\in\{0;1\}$.

**პასუხი:** $(2;\,5)$ და $(7;\,2)$.
:::
:::

:::example საშუალო
ამოხსენით მთელ რიცხვებში $xy-2x-3y=1$.
:::solution
დავამატოთ $6$ ორივე მხარეს: $xy-2x-3y+6=7$, ანუ $(x-3)(y-2)=7$.

$7$-ის მთელი გამყოფები: $\pm1,\pm7$. ამიტომ $(x-3;\,y-2)$ არის $(1;7)$, $(7;1)$, $(-1;-7)$ ან $(-7;-1)$.

**პასუხი:** $(4;\,9)$, $(10;\,3)$, $(2;\,-5)$, $(-4;\,1)$.
:::
:::

:::example რთული
ამოხსენით ნატურალურ რიცხვებში $\dfrac1x+\dfrac1y=\dfrac13$.
:::solution
გავამრავლოთ $3xy$-ზე: $3y+3x=xy$, ანუ $xy-3x-3y+9=9$:
$$(x-3)(y-3)=9.$$
ვინაიდან $\frac1x<\frac13$, $x>3$; ანალოგიურად $y>3$. ამიტომ ორივე მამრავლი დადებითია: $(1;9)$, $(3;3)$, $(9;1)$.

**პასუხი:** $(4;\,12)$, $(6;\,6)$, $(12;\,4)$.
:::
:::

## გავრცელებული შეცდომები

- **უარყოფითი გამყოფების დავიწყება.** მთელ რიცხვებში $(x-3)(y-2)=7$-ს ოთხი ვარიანტი აქვს და არა ორი.
- **მხოლოდ ერთი ამონახსნის პოვნა.** წრფივ განტოლებას, თუ ამონახსნი აქვს, უსასრულოდ ბევრი აქვს მთელ რიცხვებში — საჭიროა ზოგადი ფორმულა.
- **„ნატურალური“ და „მთელი“ არევა.** პირობა წყვეტს, ჩავთვალოთ თუ არა $0$ და უარყოფითი რიცხვები.
- **წყვილის თანმიმდევრობა.** $(4;12)$ და $(12;4)$ სხვადასხვა ამონახსნია.

## შეამოწმე თავი

:::check
აქვს თუ არა მთელი ამონახსნი განტოლებას $6x+9y=10$?
:::answer
არა: $\gcd(6,9)=3$, ხოლო $3\nmid10$.
:::
:::

:::check
აქვს თუ არა მთელი ამონახსნი განტოლებას $x^2+y^2=2023$?
:::answer
არა: კვადრატების ჯამი $4$-ზე გაყოფისას იძლევა $0$, $1$ ან $2$ ნაშთს, ხოლო $2023$ იძლევა $3$-ს.
:::
:::

:::check
ამოხსენით ნატურალურ რიცხვებში $2x+3y=12$.
:::answer
$y$ ლუწი უნდა იყოს და $3y<12$: $y=2$, $x=3$. პასუხი: $(3;\,2)$.
:::
:::
